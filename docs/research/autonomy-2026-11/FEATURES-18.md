# 18 возможностей и 7 функций: что сделано, что частично, чего нет

Источник задачи — шесть скриншотов в `ЗАДАЧА/` (список «Ещё 18 возможностей для J.A.R.V.I.S.» и список «7 функций, которые я бы добавил»). Ниже — честная сверка с кодом на 06.11.2026. Статус ставится по факту: **есть** — работает и покрыто тестами; **частично** — работает часть заявленного; **нет** — не реализовано.

Главная мысль со скриншота: важнее всех 18 — Mission Engine, то есть цепочка «цель → планировщик, память, инструменты, проверка → проверенный результат: отчёт, изменения, тесты, оставшиеся проблемы».

## Mission Engine

| Что заявлено | Статус | Где |
|---|---|---|
| Цель → план → действия → независимая проверка → критерии приёмки → отчёт | **есть** | `src/tasks/executor.js`: `plan`, шаги, `finishStep` (проверка через `src/tasks/verify.js`), `src/tasks/criteria.js`, `renderReport` |
| Отчёт: результат, изменения, тесты, оставшиеся проблемы | **есть** | `renderReport`: разделы «Объективно проверено», «Изменения в файлах», «Тесты», «Оставшиеся проблемы», «Непроверенные шаги», «Расход» |
| Остановка на ходу и продолжение | **есть** | `src/control/stop.js`, `queue.pause/resume`, эпоха стопа в `executor.js` |
| Исправление ошибок и повтор шага | **есть** | `failStep`, лимиты неудач, `MAX_STEP_ITERATIONS`; отчёт не приукрашивает |
| Откат изменения файла | **есть** | `backups/` перед перезаписью, `workspace_restore`, копия видна в отчёте |
| Проверка в настоящем окне | **есть** | запуск Electron с `--remote-debugging-port`, DOM и IPC читаются живьём (см. `STATUS.md`, заход 12) |

## Приоритеты со скриншота и что по ним сделано

Скриншот прямо называет их приоритетами разработки, а не оценкой готовности:

1. **Движок автономных целей** — есть: исполнитель с мандатом, проверками и отчётом; отчёт теперь отвечает «изменения, тесты, оставшиеся проблемы».
2. **Память задач и их продолжение** — есть: `tasks.json`, пауза/продолжение, `task_note`, `recoveryAfterRestart`.
3. **Обучение на успешных действиях** — частично: сохраняется порядок подтверждённых инструментов; аргументы и состояния интерфейса — нет.
4. **Проактивные задачи** — есть: расписание миссий и поводы для сообщений.
5. **Разговорный голосовой режим** — частично: потоковая озвучка и диктовка; перебивания голосом нет.
