# Сравнение

| Критерий | A: верхняя навигация | B: компактная шапка и рейка |
|---|---|---|
| Первое знакомство | Названия разделов видны на широком экране | Иконки требуют подсказок |
| Маленькое окно | На 864 px иконки в шапке, история поверх чата | Иконки занимают постоянные 54 px ширины |
| Площадь чата | Больше ширины | Меньше ширины, особенно при открытой истории |
| Визуальная простота | Одна линия навигации | Две области управления, зато свободная шапка |
| Масштабирование числа разделов | Ограничено шириной; нужен компактный режим | Проще добавить пункты по вертикали |

## Рекомендация: A

A убирает причину недовольства — постоянную левую рейку — и отдаёт ширину беседе. На больших размерах названия понятнее, на 864 px все четыре раздела остаются доступными через иконки с названиями для доступности. B полезен, если количество разделов заметно вырастет, но постоянная рейка возвращает прежнее ощущение пустой боковой полосы и уменьшает чат. Рекомендация предварительная: нужно оценить оба варианта визуально и проверить доступность на настоящем приложении.
