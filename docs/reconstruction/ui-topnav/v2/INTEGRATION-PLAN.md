# Внедрение — только после отдельного разрешения

1. Дождаться завершения параллельных исправлений, перечитать актуальный git diff и согласовать изменения с владельцем. Не заменять изменённые другими агентами файлы.
2. Проверить реальную привязку `data-nav`, экранов, переключателя аккаунта, тем, режимов и управления окном; перенести только размещение без изменения функций и без повторного создания обработчиков.
3. Предусмотреть перетаскиваемую область Electron и `no-drag` у кнопок, все темы, фокус клавиатуры и восстановление фокуса drawer; не добавлять дубли кнопок.
4. Оставить нетронутыми orb-nox.js, сообщения, шаги агента и систему подтверждений. Сверить состояние экрана при подтверждении, остановке, нескольких запросах и изменении размеров.
5. В отдельном временном профиле выполнить реальные проверки 1600×900, 1200×720, 864×520: пустые/длинные чаты, история, все разделы, профиль, настройки, окно, клавиатура, сфера. Снять исходный и изменённый экраны в одинаковых состояниях.
6. Выполнить `node --test` в обеих папках приложений; сообщить отдельно о недоступных тестах и любых ограничениях. Коммиты не создавать без просьбы.
