# NOX UI V2 — Navigation Refinement

Изолированный интерактивный эксперимент, локальные данные, без подключения к Nox.

Оболочка: 8 px внешнего отступа, общая верхняя строка 48 px, рейка 52 px (46 px на ширине до 1000), история 244 px, разрывы 8 px, существующие панели и радиусы 16 px. При 1200×720 справа 360 px, на 1600×900 — 400 px, на 864×520 — 278 px; чат занимает остаток. На малой ширине история — overlay шириной 244 px. При сворачивании истории она также открывается кнопкой в заголовке чата.

Токены из nox-screen.css: #0F0F10, #18181B, #2A2A2E, #F1F1F3, #9A9AA0 и #2E9AC1; Inter из проекта. Сфера — точная копия исполняемого исходного orb-nox.js, variant nox и scale 0.86, без изменений алгоритма.

В прототипе локально работают переключение разделов, активное состояние, история, новый чат, профиль и настройки. Содержимое страниц — демонстрационные заглушки, ввод не обращается к модели. Кнопки окна демонстрационные. Режим, сообщения и шаг агента представлены примером, а не работающими функциями.

Окончательная проверка размеров, клавиатуры и фактической читаемости не проведена: скриншотов V2 в этой среде нет. Размеры — цель конструкции, а не подтверждённый результат.
