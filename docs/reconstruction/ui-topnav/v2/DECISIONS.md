# Решения

- Не использовать предыдущие A/B: оба отклонены владельцем.
- Сохранить формы панелей, палитру, шрифт, состав рейки и движок сферы текущего Nox. Изменение касается размещения, а не создания нового продукта.
- Бренд и глобальные действия собраны в 48 px строке; навигация не дублируется сверху. Это добавляет высоту, но делает кнопки независимыми от области сферы.
- Профиль перемещён снизу наверх, настройки — из рейки наверх. Слева остаются только основные разделы, сгруппированные под верхней строкой.
- Демонстрационная беседа и строка работы показывают плотность интерфейса вместо большого приветствия.
- Из-за новой шапки на 520 px снижается вертикальная площадь чата: это явная цена концепции, которую необходимо сравнить с оригиналом в живом окне.
- Исходный Nox уже выглядит цельно; без снимков при одинаковых размерах нельзя утверждать, что V2 визуально лучше. Концепция не готова к внедрению.
