# Nox — Дизайн сферы (Phase R2)

> Сохраняем идентичность Nox: точечная оболочка + ядро. Кольца Luxify не переносим — это фирменный знак [В].
> Адаптируем принципы: дыхание, волна, деформация, цвет состояния, непрерывность.

## 1. Текущая сфера Nox [В] (orb-nox.js)

Два варианта: `wire` (проволочная сетка 112×54, линия 1px, глубина по z) и `nox` (1400 точек + 200 ядра, объёмный свет). Состояния: idle/attentive/listening/thinking/speaking/waiting_approval/error/success — уже 8.

**Что хорошо:** DPR, пауза в фоне, additive-смешение, виртуальный свет (key/rim), детерминированный ГПСЧ.

**Что правим [П]:**
- Период idle 1.8s → 2.1s (синхрон с Luxify [О] M01) — спокойнее.
- Амплитуда idle 6% → 4.5% — сейчас пухло, Luxify ±2.2% [О] — берём середину [П].
- Нет wave-лаг между слоями — добавляем 0.15s задержку ядро vs оболочка [П] (Luxify 0.33s/кольцо [О] — адаптируем).
- Нет чувствительности/инерции как ручек — добавляем (см. §6).

## 2. Визуальная спецификация состояний [П]

Все состояния — одна геометрия, разные параметры (speed/period/deform/bright/halo/spin/belt) — как сейчас, цифры обновлены:

| Состояние | Триггер Nox | Визуал | Параметры | Цвет |
|---|---|---|---|---|
| **idle** | Нет активности | Медленное дыхание, волна сверху вниз | period 2.1s, deform 4.5%, bright 1.0, halo 14%, spin 0.05, belt 1.0 | accent (#2E9AC1 или кастом) |
| **listening** | `dictation:state` listening / mic on | Рябь по сфере + ядро пульсирует `setVoice(level)` | period 1.6s, deform 6%, bright 1.1, halo 17%, belt 0.8 | accent + ярче |
| **thinking** | `agent:event` planning/searching | Быстрое дыхание, ярче, ореол сильнее | period 0.9s, deform 8%, bright 1.35, halo 22%, spin 0.14, belt 1.15 | accent светлее на 10% |
| **speaking** | `speak` / TTS | Волна в такт голосу, пояс гаснет | period 1.8s (но деформация = voice), bright 1.15, belt 0.45 | accent |
| **executing** | `agent:event` acting (шаг k/N) | Как thinking, но с бегущей точкой по поясу | period 1.1s, deform 7%, spin 0.12 | accent |
| **waiting** | `waiting_approval` | Замедление, янтарь, ореол тусклый | period 2.4s, deform 3%, bright 0.85, halo 14%, spin 0.02 | warn #F5A524 |
| **success** | `success` / verified | Вспышка + масштаб 1.04 на 220ms, изумрудный отлив | bright 1.2, halo 20% → затухает | ok #3DD68C |
| **error** | `error` / failed | Короткая дрожь 1.5% 400ms, затем статика красный | bright 1.05, halo 16% | err #FF5C5C |

`attentive` (фокус ввода) — idle глубже 6% + чуть светлее — оставляем для жестов ввода [В].

**Цвета:** все из токенов темы, не хардкод. При смене акцента палитра пересчитывается `pal()` — уже есть. Контраст сферы на фоне не ниже 3:1 — проверяем `themes.test.js`.

## 3. Связь акцентного цвета с состоянием [П]

- **idle/listening/thinking/speaking/executing** — сфера в цвете акцента (accent). При waiting/success/error — полностью перекрашивается в warn/ok/err — как Luxify [В] перекрашивал кольца при смене темы.
- Переход цвета — 280ms linear — не мгновенно как Luxify палитра [В] M07 — мягче для глаз [П].
- В светлой теме accent #2F5FD0 тёмный — сфера не теряет объём: точки светлые #EAF1FF на тёмном bg — инверсия не нужна, сфера всегда на bg/panel — контраст достаточный.

## 4. Непрерывность движения между состояниями [П]

Все переходы — миксом параметров 280ms ease-out (MIX_KEYS), без скачка формы. Геометрия не пересоздаётся. `phase`/`breath`/`rotY` не сбрасываются — волна продолжается. Исключения:
- `error` — добавляется shake 400ms, затем затухает.
- `success` — flash + scale 1.04 на 220ms, затем к idle.
- `idle → listening` — voice с 0, плавно 120ms.

Это сохраняет ощущение живой сущности, а не слайд-шоу.

## 5. Дыхание, волна, деформация [П]

- **Дыхание [О→П]:** Luxify — 2.1s, ±2.2% радиуса, волна снаружи внутрь 0.33s/кольцо. Nox — одна оболочка + ядро: делаем deform оболочки 4.5%, ядра 3% с lag 0.15s — имитация волны без колец.
- **Волнообразное движение:** точки оболочки смещаются по нормали `sin(phase + lat*2)` — уже есть. Усиливаем в listening/thinking.
- **Пространственная деформация:** эллиптичность 2% по Y в idle, 4% в thinking — уже есть `TILT 0.13` — оставляем.
- **Не приписываем Luxify аудиореактивность:** в материале её нет [О] (§3 MOTION). Реакция Nox — самостоятельное решение [П].

## 6. Чувствительность / Амплитуда / Инерция [П]

Как в настройках аватара Luxify [В] S27:

- **Чувствительность (0–100):** множитель voice level (0 = нет реакции, 100 = ×1.5). По умолчанию 50.
- **Амплитуда (0–100):** пик deform (0 = 1%, 100 = 10%). По умолчанию 50 → 4.5% idle.
- **Инерция (0–100):** сглаживание voice — `voice = lerp(voice, target, 1 - inertia)` где inertia 0.7→0.95. По умолчанию 50 → 0.85. Уже есть `voice`/`voiceTarget` с lerp — добавляем ручки.

Источник анимации — пока только TTS Джарвиса (`speak`/`tts.js` setVoice). Захват системы/микрофона — B-слой позже.

## 7. Раскадровки / последовательность кадров

См. `storyboards/sphere-states.png` и `previews/` макеты — каждый кадр сферы в контексте экрана. Отдельно — `storyboards/sphere-motion-strip.png` — лента 8 состояний × 5 фаз дыхания (0/0.25/0.5/0.75/1.0 периода) — показывает изменение во времени.

Текстовое описание (для ТЗ Opus):

- **idle:** 0s — R 100% → 0.5s — 102% (вдох) → 1.0s — 100% → 1.5s — 98% (выдох) → 2.1s — 100%. Ядро отстаёт на 0.15s.
- **listening:** базовая амплитуда + рябь `voice*2%` по меридианам, ядро пульсирует `scale 0.42+voice*0.04`.
- **thinking:** частота ×2, амплитуда ×1.8, яркость +35%, ореол +8%.
- **speaking:** деформация = voice (0→6%), пояс гаснет до 45%.
- **executing:** как thinking, пояс бежит `beltPhase += dt*spin*2`, точка-индикатор по экватору.
- **waiting:** медленно 2.4s, амплитуда 3%, цвет янтарь, спин 0.02 — почти стоит.
- **success:** вспышка bright 1.2→1.0 за 220ms + scale 1.04→1.0, изумрудный.
- **error:** дрожь X 1.5% затухает 400ms, затем красный статика.

## 8. Доступность

- `prefers-reduced-motion: reduce` → статика, только цвет [В].
- `html[data-motion="off"]` → статика [В].
- Размер 332px (240 <1000) — не мельтешит.
- Контраст сферы vs bg ≥3:1 — декоративный элемент, не текст.

## 9. Что не делаем

- Не копируем 5 плоских колец Luxify.
- Не выдаём недоказанную аудиореактивность Luxify за факт.
- Не добавляем декоративные частицы вокруг сферы — отвлекают от контента.
