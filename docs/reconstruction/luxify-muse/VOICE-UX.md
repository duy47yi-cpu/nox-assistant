# Nox — Голосовой UX (Phase R2)

> Проектная концепция, не наблюдение. В материалах Opus нет записи голоса самого Luxify — диктор ≠ приложение [В] (AUDIO-ANALYSIS). Не придумываем тембр Luxify.

## 1. Принцип

Голос — второй вход в тот же чат и команды, не отдельный режим. Все действия — через `decide`/`approvals` — как текст. Голос не обходит подтверждения [В].

## 2. Состояния микрофона (уже в Nox [В])

| Состояние | Индикатор | Поведение |
|---|---|---|
| **Слушаю** | mic accent, точка зелёная, «Слушаю» 12px | Вся речь → чат/команды |
| **Только имя** | mic #9A9AA0, «Только “Джарвис”» | Только фразы с «Джарвис» в начале [В] `src/voice/wake.js` |
| **Микрофон выкл** | mic перечёркнут, «Микрофон выкл» | Распознавание остановлено, канал освобождён |
| **Нет распознавания** | «Русское распознавание недоступно» | Честная причина, без фейка |

Переключение: индикатор у поля ввода, Ctrl+Alt+M, трей «Микрофон», фразы «тихий режим/слушай меня/хватит слушать» [В].

## 3. Визуальное состояние прослушивания [П]

**Где:** расширяем поле ввода (капсулу), не отдельный оверлей — как Luxify строка S29, но встроена [П].

**Как выглядит:**
```
┌─ Поле ввода (listening) ──────────────────────┐
│ [attach] [region]  ┌─ accent pill ─┐  волна   │
│                     │  Джарвис      │  ▐▐ ▐▐ ▐  │
│ Живой текст: «включи музыку» 13.5/18 #F1F1F3   │
│ [picks] [mic●recording] [send]                │
└──────────────────────────────────────────────┘
```
- Плашка «Джарвис» — accent pill 20px, 11/600 upper, появляется когда `wake` сработало [О V06 6.4s].
- Живой текст — под инпутом, 12/16 #9A9AA0, дописывается по мере `dictation:state` interim (если Windows отдаёт) — иначе только финальный [В] `dictation.js` — fallback на точки уровня.
- Волна — 5 столбиков 2px, 4→16px, 900ms alternate — только когда `recording=true` [В orb-nox.js уже есть].
- Mic — красный err 14% + бордер 52% [П] — как в luxify G1 синяя кнопка [В] IMG02, но красный для записи — понятнее.

**Если распознавание не отдаёт interim:** показываем точки уровня (3 точки, пульс 600ms) + «Слушаю…» — не фейковый текст [П].

## 4. Отображение распознанной речи [П]

| Стадия | Что видит пользователь | Источник |
|---|---|---|
| Interim | Серый текст с курсором `▐` мигает 530ms, обновляется каждые ~100ms | `dictation:state` interim |
| Final | Чёрный текст 13.5/18, как ввод пользователя | `dictation` final |
| Wake только | Только плашка «Джарвис» без текста | `wake.js` |
| Не распознано | Pill «🎤 Речь не распознана.» по центру ленты 12px [В] IMG12 | `dictation` error |

Живой текст не уходит в чат до конца фразы — остаётся в поле ввода, как `dictation.js` сейчас — «диктовка остаётся в поле» [В].

## 5. Индикация голосового ответа [П]

Когда Джарвис говорит (`speak`/`tts.js`):

- Сфера — `speaking` (волна в такт `setVoice(level)` 0..1) — уже есть [В].
- В ленте — карточка ответа с иконкой громкости 14px слева от `turn::before` NOX.
- В карточке — кнопка [■ Стоп озвучивания] 28px ghost + прогресс-точка.
- `voicePersona` не меняет голос, только темп/громкость [В] `personas.js`.

## 6. Прерывание озвучивания [П]

| Действие | Реакция | Состояние |
|---|---|---|
| Нажать [■ Стоп озвучивания] | `tts.stop()` + `speak` abort | `speaking` → `idle` 120ms |
| Сказать «стоп/хватит/отмена» | `approvals.js` «останови команду» — снимает и озвучку | `speaking` → `idle` |
| Начать говорить (barge-in) | Если `vad` — пауза TTS, слушает | `speaking` → `listening` 80ms |
| Нажать Esc | Стоп хода + стоп TTS | `speaking`/`executing` → `idle` |

TTS уже `speak` с `stop` [В] `tts.js` — только UI.

## 7. Реакция сферы на аудиосигнал [П]

**Источник:** пока только TTS Джарвиса (`tts.js` знает когда говорит) + `setVoice(level)` — уже есть [В]. Захват системы/микрофона — позже (B).

**Как реагирует:**
- `listening` — рябь по сфере `voice*2%` + ядро `0.42+voice*0.04` — уже в orb-nox.js.
- `speaking` — deform = voice*6%, belt гаснет до 45% — уже.
- Параметры чувствительности/амплитуды/инерции — ручки в Настройки→Сфера (см. SPHERE-DESIGN §6) [В] S27 — теперь работают.

Не приписываем Luxify реакцию на голос — её нет в кадрах [О] (M01: покой без звука, V06 волна — монтаж).

## 8. Состояние отключённого микрофона [П]

- Кнопка mic — 28px, перечёркнутая иконка #6B6B70, бордер #2A2A2E.
- При нажатии send — текст уходит как обычно, mic не нужен.
- Tooltip: «Микрофон выключен — включите для голоса (Ctrl+Alt+M)».
- В ленте нет плашек «микрофон выкл» — не шумим.

## 9. Ошибки распознавания и озвучивания [П]

| Ошибка | Плашка/баннер | Цвет | Действие |
|---|---|---|---|
| Речь не распознана | «🎤 Речь не распознана.» центр ленты 12px | surface + border, text-2 | Подсказка «Попробуйте ещё раз» |
| Ошибка TTS (нет голоса) | «Озвучивание недоступно» под карточкой 12px | err-bg + err-line | Кнопка «Повторить» |
| Микрофон занят другим приложением | Баннер в поле ввода 12px | warn-bg | «Освободите микрофон» |
| Нет сети для Fish/OpenAI (если выбрано) | «Голос недоступен офлайн» | warn | Fallback на Silero |

Все ошибки — 12/16, не кричат красным на всю ленту — только у места действия.

## 10. Что не реализуем

- Голосовой движок — уже есть Silero + Fish [В] — не трогаем.
- Подключать платные/неофициальные API — запрещено.
- Копировать голоса Luxify (Jarvis/Friday/GLaDOS) — юридический риск [В].
- Выдумывать характеристики голоса Nox как факт — только концепция для утверждения.
