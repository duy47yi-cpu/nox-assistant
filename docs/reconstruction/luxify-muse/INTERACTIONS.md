# Nox — Спецификация взаимодействий (Phase R2)

Формат для каждого компонента: Начальное → Действие → Реакция → Переход → Конечное → Ошибка/восстановление → Повтор.

> Не заменяем backend-поведение анимацией. Не снижаем требования подтверждения ради простоты [В].

## 1. Навигация по рейке

- **Начало:** Главная, активная «Главная» accent-soft.
- **Действие:** Клик по «Команды».
- **Реакция:** Лента гаснет 80ms, новая `viewIn` 200ms ease-out, черта переезжает 200ms, URL не меняется (view — data-view).
- **Конец:** Команды, активная «Команды».
- **Ошибка:** Модуль не загрузился — баннер err + «Повторить» — остаётся на прежней.
- **Повтор:** Клик по активной — ничего (не перезагружает).

## 2. Новый чат

- **Начало:** Список чатов с N чатами, лента с сообщениями.
- **Действие:** Клик «+ Новый чат» или Ctrl+N.
- **Реакция:** `chatList` → новый чат в истории, лента очищается, `is-empty` true, фокус в поле ввода, скролл вниз.
- **Переход:** 200ms cross-fade.
- **Конец:** Пустое «С чего начнём?».
- **Ошибка:** Нет моста — тост err, не создаёт.
- **Повтор:** Создаёт ещё один пустой — счётчик чатов +1.

## 3. Отправка сообщения

- **Начало:** Поле ввода с текстом, send enabled.
- **Действие:** Enter или клик send.
- **Реакция:** Пузырь пользователя в ленте 200ms rise, поле очищается, `agent:event` → карточка агента появляется, сфера → thinking, working timer.
- **Конец:** Ответ в ленте + карточка done + плашки шагов.
- **Ошибка:** Нет сети/модели — баннер err в ленте + плашка «✕ Провалено».
- **Повтор:** Пока `working` — send → `chatStop` (если есть), иначе disabled.

## 4. Стоп хода

- **Начало:** Карточка агента с [■ Стоп], сфера thinking/executing.
- **Действие:** Клик Стоп или Esc.
- **Реакция:** `control:stop` → карточка → «— Остановлено» 120ms, сфера → idle, плашки — «— Отменено» для незавершённых.
- **Конец:** Лента с частичным результатом.
- **Ошибка:** Уже остановлено — игнор.
- **Повтор:** Второй Esc — ничего.

## 5. Подтверждение в карточке агента

- **Начало:** `waiting_approval` — approval блок раскрыт 170ms, отсчёт 30s, сфера waiting (янтарь, 2.4s).
- **Действие:** Клик «Разрешить» или фраза «да/давай/подтверждаю» в «Слушаю» [В].
- **Реакция:** `approval:respond(true)` → блок схлопывается 120ms, точка синяя→зелёная 120ms, «✓ Готово» 200ms, сфера → thinking → success.
- **Конец:** Шаг выполнен, следующий.
- **Ошибка:** Авто-отмена 30s → «— Отклонено» + «Отменено (таймаут)» — как сейчас [В].
- **Повтор:** Клик «Отклонить» → `approval:respond(false)` → «— Отклонено».

## 6. Дерево команд — выбор и действия

- **Начало:** Список строк, одна выбрана (accent-soft).
- **Действие:** Клик по строке.
- **Реакция:** Выделение переезжает 120ms, справа появляются 3 кнопки 28px fade 67ms.
- **Конец:** Строка выбрана.
- **Ошибка:** Нет прав — бордер err.
- **Повтор:** Клик по выбранной — ничего; двойной клик → редактор.

## 7. Дерево — вкл/выкл

- **Начало:** Выбрана, кнопка ⏻ видима.
- **Действие:** Клик ⏻.
- **Реакция:** Строка 45% opacity, флажок, тост «Отключено».
- **Конец:** Отключена, не запускается [В].
- **Ошибка:** — 
- **Повтор:** Клик ⏻ снова → 100% opacity.

## 8. Редактор — сохранить

- **Начало:** Изменены поля — «Сохранить» accent [В].
- **Действие:** Клик Сохранить.
- **Реакция:** `commands:save` → тост «Сохранено», кнопка → ghost, dirty false.
- **Конец:** Сохранено.
- **Ошибка:** Конфликт имён — баннер err + подсветка поля.
- **Повтор:** Сохранить без изменений — disabled.

## 9. Добавление шага — выбор действия

- **Начало:** Редактор, кнопка «Действие».
- **Действие:** Клик Действие.
- **Реакция:** Модалка «Список действий» 240ms rise, scrim 40%, поиск фокус.
- **Конец:** Модалка открыта.
- **Ошибка:** Каталог пуст — «Нет действий» + «Добавить пустое».
- **Повтор:** Esc → закрыть 120ms fade.

## 10. Контекстное меню

- **Начало:** Курсор над строкой дерева.
- **Действие:** Правый клик.
- **Реакция:** Меню 180px, 67ms fade, 11 пунктов.
- **Конец:** Меню открыто, фокус на первом.
- **Ошибка:** Нет clipboard — пункт «Вставить» disabled.
- **Повтор:** Клик вне → закрыть, клик по пункту → действие + закрыть.

## 11. Поиск по настройкам

- **Начало:** Настройки, все разделы видны.
- **Действие:** Ввод «инт» в поиск.
- **Реакция:** Фильтр по подписям 120ms cross-fade, остаётся «Интерфейс» [В V08].
- **Конец:** Отфильтровано, чипы подсвечены.
- **Ошибка:** Ничего не найдено — «Ничего не найдено» 12/16 text-2.
- **Повтор:** Очистить → все разделы 120ms.

## 12. Сброс раздела ↻

- **Начало:** Раздел «Интерфейс» изменён.
- **Действие:** Клик ↻.
- **Реакция:** Confirm «Сбросить раздел?» → сброс токенов → тост «Сброшено», сфера перекрашивается если был цвет.
- **Конец:** Дефолт раздела.
- **Ошибка:** Не изменён — ↻ disabled 45%.
- **Повтор:** Снова ↻ — disabled.

## 13. Палитра цвета

- **Начало:** Поле HEX с образцом 20×20.
- **Действие:** Клик по образцу.
- **Реакция:** Палитра квадрат + полоса 240ms rise.
- **Действие 2:** Тянуть оттенок.
- **Реакция:** Сфера и интерфейс перекрашиваются в том же кадре [В M07] + 280ms lerp сферы [П].
- **Конец:** «Готово» → применить + readable() сдвиг если нужно 4.5:1 + подсказка [В].
- **Ошибка:** Невалидный HEX — бордер err + «Неверный цвет».
- **Повтор:** «Отмена» → откат.

## 14. Голос — прослушивание

- **Начало:** Mic off, поле пустое.
- **Действие:** Клик mic или фраза «Джарвис».
- **Реакция:** Mic красный, плашка wake accent, волна 900ms, живой текст серый + курсор, сфера listening.
- **Конец:** Final → текст в поле ввода, mic → idle 120ms.
- **Ошибка:** «🎤 Речь не распознана.» pill центр [В], сфера idle.
- **Повтор:** Mic снова → listening.

## 15. Озвучивание — стоп

- **Начало:** Карточка ответа с 🔊, сфера speaking.
- **Действие:** Клик [■ Стоп озвучивания] или «стоп».
- **Реакция:** `tts.stop()` 80ms, сфера → idle, кнопка → «Озвучено».
- **Конец:** Тишина, текст остаётся.
- **Ошибка:** Уже остановлено — игнор.
- **Повтор:** «Озвучить снова» → speaking.

## 16. Сфера — переключение варианта

- **Начало:** Nox (точки) 332px idle.
- **Действие:** `NoxScreen.setVariant(''wire'')` (dev).
- **Реакция:** Пересоздание геометрии 120ms cross-fade, состояние сохраняется.
- **Конец:** Wire 332px idle.
- **Ошибка:** Неизвестный вариант → fallback core [В].
- **Повтор:** Обратно — так же.

## 17. Оверлей «только сфера»

- **Начало:** Главное окно 1200×720.
- **Действие:** Включить «Сфера на рабочем столе» в Настройках.
- **Реакция:** Новое окно 280×280 без рамки, прозрачное, сфера + mic, позиция 3×3.
- **Конец:** Оверлей видимый, игнор мыши вне hover.
- **Ошибка:** Полноэкранная игра — автоскрытие [В] S27.
- **Повтор:** Выкл → окно закрывается.

## 18. Тема — переключение

- **Начало:** Dark, Nox bg #0F0F10.
- **Действие:** Выбор Light в Настройках.
- **Реакция:** `JarvisTheme.apply(''light'')` → html[data-theme="light"] → все панели + сфера перекрашиваются 280ms linear (сфера) + 200ms ease-out (панели). Без перезагрузки [В].
- **Конец:** Light bg #F4F1EB, текст #17140F, accent #2F5FD0, сфера синяя ярче.
- **Ошибка:** Неизвестная тема → fallback dark [В].
- **Повтор:** Обратно — так же.

Все взаимодействия — клавиатура: Tab/Shift+Tab, Enter/Space, Esc — как сейчас [В].
