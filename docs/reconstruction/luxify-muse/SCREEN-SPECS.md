# Nox — Спецификация экранов (Phase R2)

1200×720 — базовый размер (как `nox-shot.js` и Luxify V07/V08 1280×720). 864×520 — узкий вариант — пропорции сохраняются, но не специфицируем отдельно — уже есть в `nox-screen.css`.

## 1. Главный экран и сфера

**Сетка:** `rail 52 | history 244 | chat 1fr (=~580) | sphere 360` + gap 8, padding 8, radius 16/12 [П].  
**Фон:** `bg` (#0F0F10 dark, #F4F1EB light) — семантический, не хардкод.  
**Рейка:** 5 пунктов (Главная/Команды/Подключения/Настройки/Аккаунт) + Свернуть скрыт. Активный — accent-soft 14% + левая черта 4×22 accent. Иконки 18px, бордер-радиус 10.  
**История:** заголовок 16/600, кнопка + Новый чат 32px pill, группы Сегодня/Ранее 11px upper #6B6B70, строки 36px, активная 9% белого. Скролл без скроллбара.  
**Чат:** feed padding 12/20/12, gap 20. Пользователь — surface-3 справа 72%, 16/16/4/16, 13.5/20. Ответ — без пузыря, метка NOX 11/600 #6B6B70. Поток без каретки. Под ответом — копирование 26×22.  
**Сфера:** канвас 332px, центр 50.8% высоты окна, padding-bottom 32 (как сейчас). Состояния — см. SPHERE-DESIGN. Опция anchored — сдвиг +64px вправо с clip [П].  
**Поле ввода:** капсула surface-3, 16px, фокус — двойной бордер accent 30%. Левая группа: attach 28px, region 28px. Центр: input 13.5/18, placeholder #6B6B70. Правая: picks pill 28px, mic 28px круг, send 28px accent. На узком — picks сокращается до 88px, текст ellipsis.  
**Пустое:** «С чего начнём?» 22/600 центр — 40px padding.

*Состояния:* `empty` (история скрыта, в шапке NOX), `idle` (лента с сообщениями), `streaming` (md.is-streaming, кнопка копирования скрыта), `working` (карточка агента видима).

## 2. Агент выполняет многошаговую задачу

**Композиция:** та же сетка, но в ленте — карточка агента (макс 520px, 100% на узком).

**Карточка агента [П] (в ленте, не оверлей):**
- Контейнер: surface-2, border 1px, 16px, padding 12px, gap 10px, тень `0 8px 24px #00000066` на dark.
- Header 36px: точка 8px (цвет состояния) + «Агент Nox» 13/600 + «Шаг 2 из 4» 12/500 #9A9AA0 + справа [■ Стоп] 28px (surface-3, бордер, hover — err 14%).
- Action 32px: иконка 16px + «Составляю план…» 13.5/20. Когда target != null — синяя обводка 2px accent вокруг цели (в ленте — текст-ссылка с underline).
- Approval (когда waiting_approval): появляется раскрытием 170ms ease-out (Luxify [О] M08) — разделитель + щит 16px + «Нажать «Отправить» в Почта?» 13/600 + «Будет отправлено: “Привет…”» 12/16 #9A9AA0 + две кнопки 32px: Отклонить (ghost) и Разрешить (accent). Отсчёт 30с в углу.
- Done: точка зелёная, «✓ Готово · 3 шага · Проверено 2/3» 12/16, кнопка «Сохранить как команду» 28px ghost.

**Плашки шагов в чате [П]:** после каждого шага — узкая pill по центру ленты, 12/16, surface, бордер, иконка 10px: `✓ Выполнено` (только если verified=true), `○ Не проверено`, `✕ Провалено`, `— Отменено`. Цвет — text-2, не зелёный, пока нет verify [В].

**Сфера в этом экране:** thinking (0.9s, ярче) во время act, waiting_approval (янтарь, медленно) во время await, success/error после.

## 3. Голосовой разговор

См. VOICE-UX.md. Визуально:

- Поле ввода расширяется на 8px по высоте, показывает волну (5 столбиков 2px, animation nox-wave 900ms) + живой текст 13.5/18 #F1F1F3 + плашка «Джарвис» accent pill слева [П].
- Когда слушает — mic красный 14% err + бордер 52% err.
- Когда говорит — сфера speaking (волна в такт setVoice), в ленте — карточка ответа со значком громкости и кнопкой [■ Стоп озвучивания].
- Ошибки: «🎤 Речь не распознана.» — pill центр, как в IMG12 [В]; «Микрофон выключен» — баннер warn.

## 9. Общие состояния

- **Загрузка:** скелетон 200ms fade-in.
- **Пусто:** иллюстрация-точки + текст 13/16 #6B6B70.
- **Ошибка сети:** баннер err 12/16 + кнопка Повторить.
- **Модалка:** scrim #00000066 (светлая #10141A66), панель surface, border, 16px, `dialogRise` 240ms ease-out, закрытие по Esc/✕/клику вне — как сейчас [В].
- **Тост:** 32px, surface-3, border, 12/16, `toastIn` 180ms, 3s, внизу справа.

Размеры — в CSS-пикселях, DPR до 2 — как в orb-nox.js.
