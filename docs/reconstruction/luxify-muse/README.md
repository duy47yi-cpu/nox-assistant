## Ключевые решения, требующие утверждения

1. **Сфера якорь за край vs в колонке** — по умолчанию в колонке, якорь — флаг `data-sphere="anchored"` (+64px)
2. **Светлая тема** — панели #FFFDF9, акцент #2F5FD0, сфера ярче — контраст проверить
3. **Вкладки столов на Главной** — оставить историю слева или добавить вкладки столов над чатом
4. **Дублировать плашки шагов в ленту** — да/только журнал
5. **Подтверждение в карточке агента** — текст «что уйдёт» достаточно выделен?
6. **Прозрачность по умолчанию** — 0% или 8%
7. **Кольцо шагов вокруг сферы** — оставить или убрать дубль карточки
8. **Цена в чате** — показывать расход ₽ или нет

См. `OPEN-QUESTIONS.md` (19 вопросов) и `OPUS-IMPLEMENTATION-HANDOFF.md` §2.

## Система тем — критично

Проблема «не переключается тема» подтверждена [В]: `nox-screen.css` изолирован `--nox-*` от `themes.css`.  
Решение [П]: алиасы `--nox-bg: var(--bg)` и т.д. + сфера слушает `--accent`. Все поверхности — через семантические токены, контраст ≥4.5:1, сфера перекрашивается 280ms.

## Сфера

Точечная оболочка + ядро — идентичность Nox сохранена [В]. Адаптированы принципы Luxify [О]:
- дыхание 2.1с ±2.2% → Nox 4.5% + lag ядра 0.15с [П]
- волна снаружи внутрь [О] → deform оболочки 4.5% + ядро 3%
- цвет состояния [В] → перекраска 280ms + анимация различна
- Состояния: idle / listening / thinking / speaking / executing / waiting / success / error — см. `SPHERE-DESIGN.md` + `storyboards/`
