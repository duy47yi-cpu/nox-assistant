## 0. Метод и происхождение решений

Каждое решение помечено:

- **[В]** Подтверждено референсом — видно в исходнике Luxify или в коде Nox без оценки

## PHASE 1 — Visual Validation результатов Opus

### Что подтвердилось при проверке

1. **Композиция Главной со срезанной сферой — верна** [В]. На всех поколениях G1→G4 сфера — фон-якорь, центр у правого края окна, доля 40–46% ширины (VISUAL-ANALYSIS §1, DESIGN-TOKENS `orb-zone`). У Nox сейчас сфера в своей колонке 360px целиком — теряется приём.  
2. **Один акцент на всё** — перекрашивает кнопки, переключатели, пузыри, сферу одновременно [В] (V08 22–30, IMG04). В Nox `accent.js` уже так, но сфера Nox не всегда берёт `--user-hue` — дефект темы.
3. **Дыхание сферы G1** — 2.1с ±2.2% с волной внутрь (lag 0.33с/кольцо) [О] (M01, `V08-orb-ring-edges.csv`, R² 0.90 внешнее). Это покой, не реакция на звук.
4. **Смена страниц: два режима** — мгновенно (2 кадра, V08) [В] и проявление 220–270мс ease-out (V07) [О]. Обе сборки G1 — нельзя выбрать «новее».
5. **Источник анимации сферы существует как настройка** — «Голос ассистента / Все звуки / Выбранные приложения / Микрофон / Комбинированный» + Чувствительность/Амплитуда/Инерция [В] (S27, V08 53–61). Реакции в кадрах нет — только заявка.
6. **Плашки шагов агента и строка расхода** — центр-лента, «— выполнено», «🎤 Речь не распознана», `Использовано: ≈104₽` [В] (IMG12). Цена и имя модели Nox показывать нельзя по правилам проекта.
7. **Палитра с живым предпросмотром** — цвет и сфера меняются в том же кадре во время тяги [В] (M07).
8. **Голосовая строка — только макет** [C] (S29, V06 5–8). Живой текст и точки уровня — графика ролика, в приложении строки нет. Нельзя выдавать за факт.

### Что оспорено / уточнено

- **Размеры:** пиксели V07/V08 — пиксели видео 720p, масштаб к экрану ×1/0.6 [О] — оценка по пропорции 16:10→1920×1200. Используем только доли, не пиксели — см. DESIGN-SYSTEM §2.
- **Толщина бордера карточки** ~1px с alpha 0.06–0.08 [О] — на 720p размыто, точное число нельзя.
- **Шрифт G2** — не Inter, а геометрический гротеск (Manrope/Onest/Gilroy-подобный) [О] — по рисунку, файла нет. Для Nox оставляем Inter — см. DESIGN-SYSTEM §4.
- **Цвета из видео** — ±6 по каналу из-за H.264 [О]. Точные только #4466FF/#0A0A0A из полей настроек [В].
- **Столы/виджеты G3/G4, агент, MCP-орбита** — ролики в наклоне с монтажом — размеры сетки, анимации вкладок, смена стола — не измерить. Берём принципы, не пиксели.

### Что не переносим

- Логотип Luxify, имя, 5 плоских колец как знак, картины арт-серии, обложки голосов-персонажей (Jarvis/Edith/GLaDOS) — юридический риск [В] (IMPLEMENTATION-RISKS §3).
- Счётчики «41 594 сервера», «30 виджетов» — монтажная графика.

## PHASE 2 — Design Direction: собственная система Nox

### Принципы Nox (приоритет из брифа)

1. Красивый минимализм — один акцент, одна сфера, повторяемая карточка, много воздуха (шаг строки 29 при кегле 15 из G2 [О]).
2. Цельность — те же радиусы/бордеры/отступы во всех разделах.
3. Польза — нет декора ради декора; каждая линия — состояние.
4. Плавность — 120/200/280мс, ease-out 0.16,1,0.3,1 (уже в Nox).
5. Живая сфера — центр внимания, но не перекрывает контент.
6. Удобство агента — номер шага, цель, Стоп, подтверждение «что уйдёт» в одном месте.
7. Совместимость — не ломаем существующие `renderer/nox-*`, `settings-nav`, `desks`, `mcp`, `journal`.
8. Темы — все поверхности через семантические токены, сфера поддерживает акцент, контраст ≥4.5:1.

### Текущая база Nox: что работает и что нет

**Работает [В] (код):**
- Сетка 1200×720: rail 52 / history 244 / chat 1fr / sphere 360 / gap 8 — пропорция близка к Luxify 15/43/40, читается.
- Токены тем в `themes.css` — 12 тем + `system`, `theme-boot.js` до отрисовки, `jarvis.accent` с проверкой 4.5:1 и сдвигом.
- Орб `orb-nox.js` — два варианта (wire/nox), 8 состояний, DPR, пауза в фоне, `setVoice(0..1)`.

**Недостатки (выявлены):**
- **Тема экрана Nox изолирована** [В]: `nox-screen.css` задал `--nox-bg:#0F0F10` и т.д. на `body[data-view="nox"]`, не читает `themes.css`. Переключение темы не влияет на Nox — жалоба из брифа подтверждена. Фикс: семантические токены (см. THEMES.md) [П].
- **Сфера не уходит за край** [В]: текущая колонка 360px с padding 12 — эффект якоря потерян. Нужна опция «среза» без ломки `nox-shot.js` эталонов.
- **Плотность чата** низкая: пустых 40px вокруг `chatEmpty` — много для 1200px. Берём плотность G2: шаг 29/15.
- **Строка хода** — текст с секундомером, нет номера шага k/N и цели клика [В]. Данные есть (`agent:event` runId/step/status/label/target) — только вид.
- **Плашки шагов после хода** — нет. «Выполнено» можно только по `verification` [В].
- **Стекло** — есть (`--win-alpha`, `--win-radius`, `--glass-blur`), но Nox-экран его не использует.

### Навигация и композиция окна [П]

**Окно:** без системной рамки, скругление 12px, бордер 1px rgba(42,42,46,0.8) [В]. Сохраняем.

**Рейка [П]:** 52px (46px <1000px), только иконки, активная — `accent-soft` 14% + синяя черта 4×22 слева [О по G2]. Hover — 6% белого, без сдвига (сейчас `translateX(2px)` — убираем, чтобы не дёргать сферу). Свёрнутый/свёрнутый — Nox уже свернут по умолчанию — оставляем.

**История [П]:** 244px (176px <1000px), заголовок 16/600, кнопка + Новый чат 32px pill с бордером. Группы «Сегодня/Ранее», строка 36px, активная — 9% белого + 1px бордер 7%. Высота строки G2 — 30px при 15pt — у нас 36px при 13px — оставляем 36px для тача, плотность компенсируем отступами 8px.

**Чат [В+П]:** 1fr, `convo` без бордера, `feed` 20px по бокам, gap 20px между сообщениями (сейчас 20). Пузырь пользователя — `surface-3` с бордером справа (не accent — чтобы не спорить с сферой). Ответ — без пузыря, метка NOX 11/600 #6B6B70. Максимум строк чата в ленте — не трогать.

**Сфера [П]:** колонка 360px (278px <1000px), `orb-size` 332px (240px). **Опция среза [П]:** при `data-sphere="anchored"` канвас сдвигается на +64px вправо (`transform: translateX(18%)`) и `overflow: clip` — центр уходит к краю, эффект Luxify без смены сетки. По умолчанию `contained` — как сейчас, чтобы не ломать скриншоты. Владелец выбирает в Настройки→Вид → «Сфера: в колонке / якорь за край».

**Поле ввода [П]:** капсула 16px, бордер, фокус — двойной бордер accent 30% + bg. Выбор модели `pick-trigger` 28px pill, микрофон 28px круг, отправка 28px круг accent. Ширина контейнера — на всю ширину чата, не плавающая.

### Главный чат [П]

- Пустое: «С чего начнём?» 22/600 по центру, 40px padding — оставляем, но уменьшаем до 32px, чтобы не «проваливался».
- Лента: `nox-rise` 200ms ease-out для каждого нового элемента — уже есть.
- Поток ответа: без каретки, просто обрыв — как в референсе (там каретки нет).
- Под ответом — кнопка копирования 26×22 с бордером, появляется после `is-streaming` [В].
- Строка хода — заменяем на агент-карту (см. ниже).

### Расположение сферы [П]

Центр сферы — 50.8% высоты окна, чуть выше центра панели (из `nox-screen.css` padding-bottom 32). Сохраняем. На узком окне sphere-w 278 — сфера 240 — не перекрывает чат. При anchored — clip, тень не вылезает.

### Карточки автономного агента [П]

**Сейчас:** `nox-working` — строка с секундомером.  
**Становится [П]:** компактная карточка агента в ленте чата (не оверлей), ширина 100% ленты, макс 520px.

Структура:
```
┌─ Карточка агента ──────────────────────┐
│ ● Агент Nox  Шаг 2 из 4          [■ Стоп]  ← header 36px
│ ───────────────────────────────────────
│ ○ Составляю план… (или Нажимаю «Написать» в Почта)  ← action 32px
│   └─ синяя обводка цели есть только когда target != null
│ ───────────────────────────────────────
│ [Отклонить]  [Разрешить →]  + «Будет отправлено: "…"»  ← approval, появляется 170мс ease-out, высота 80→200
│ ───────────────────────────────────────
│ ✓ Готово  ·  3 шага  ·  Проверено 2/3  [Сохранить как команду]
└────────────────────────────────────────┘
```
- Точка состояния: синяя (plan/act), янтарь (await), зелёная (done), красная (error) — как в Luxify [В], но цвета из токенов warn/ok/err, не хардкод.
- Номер шага — из `step.runId`/`status` [В].
- «Стоп» — `esc-stop`/`control` уже есть.
- Подтверждение — текст из `approvals.js` `target` + цитата — в самой карточке, не модалькой (Luxify — в карточке [В] S31).
- «Сохранить как команду» — после `done`/`succeeded`, ведёт в редактор (сейчас уже есть `experience.js` подсказка — делаем явной кнопкой).

### Визуализация последовательности [П]

- Кольцо шагов вокруг сферы (как в `orb-variants.js` бусины) — оставляем как второй индикатор, но не основной. Основное — карточка + плашки в чате.
- Плашки в чате после каждого шага — узкие, по центру, 12px, бордер, иконка статуса: `✓ выполнено`, `○ не проверено`, `✕ провалено`, `— отменено`. Цвет — нейтральный, не зелёный, пока нет `verified` [В] (IMPLEMENTATION-RISKS).

### Подтверждения [П]

Не снижаем требования `hardDeny`/`decide` ради визуала.  
В карточке агента — блок approval с 2 кнопками + 30с отсчёт (уже есть). Вне агента (одиночные опасные инструменты) — диалог с затемнением `scrim` 40% и `dialogRise` 240ms.

### Команды и редактор [П]

Сохраняем `nox-commands.css` каркас. Уточнения:
- Дерево — строки 36px (сейчас 64px — слишком крупно для списка 20 команд), отступ уровня 16px с направляющими 1px #2A2A2E [О по V07].
- Выбрана — accent-soft 14%, справа 3 кнопки 28px (✎ ⏻ 🗑) появляются только на hover/выбор [В S06].
- Отключена — 45% opacity + зачёркнутый label.
- «Сохранить» — accent только когда dirty (как Luxify) [В].
- Поиск — с лупой слева, `focus` — accent-бордер.
- Каталог паков — карточки 2 в ряд 486×125 [О IMG08], но на 1200px — 1 в ряд с правой колонкой категорий — уже есть, оставляем.
- Выбор действия — модалка с колонкой описания справа [П] (S09) + автодополнение под полем [П] (S10).

### Подключения [П]

## Токены Nox как база: недостатки

- Токены экрана Nox (`--nox-*`) не наследуют `themes.css` — светлая тема ломается [В]. Фикс: семантические токены (`--bg`/`--surface-*`/`--border`/`--text-*`) — см. THEMES.md.
- Радиусы 16px везде — крупнее Luxify 10–14px [О] — оставляем 16px: Nox крупнее, воздух нужен.
- Акцент #2E9AC1 темнее Luxify #4466FF — ближе к Nox-циану #58D9E8 из themes.css — оставляем, но делаем токеном `--accent`.
- Межстрочный 20/13.5 = 1.48 — у Luxify 1.9 — Nox плотнее, читается лучше для длинных ответов — оставляем.

## Что не создаём

- Новый экран, несовместимый с уже работающими `nox-screen`, `nox-commands`, `nox-connections`, `nox-settings` — запрещено [В].
- Декоративные элементы без функции.
