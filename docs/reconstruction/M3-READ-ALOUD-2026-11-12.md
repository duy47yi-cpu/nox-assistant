# М3: чтение вслух — выделенное, документ, пауза, продолжение, стоп (12.11.2026)

Раньше `read_clipboard_aloud` умел одно: прочитать буфер обмена целиком и замолчать. Ход при этом был занят,
поставить на паузу и продолжить было нечем. Теперь это чтение с управлением.

## Что умеет

| Что | Как |
|---|---|
| Прочитать буфер | `read_clipboard_aloud` без аргументов |
| Прочитать выделенное | `source: "selection"` — текст берётся у выделения через UI Automation, буфер обмена не трогается |
| Прочитать документ | `source: "file"`, `path: "…"` — txt, md, json, csv, log, ini, yml, js, ts, py, ps1, sh, xml, sql, html, docx |
| Пауза | `action: "pause"` — звук обрывается сразу, место запоминается |
| Продолжить | `action: "resume"` — с того же куска, не с начала |
| Остановить | `action: "stop"`; аварийный стоп (Ctrl+Alt+Shift+K) тоже прекращает чтение |
| Где я | `action: "status"` — «читаю: 3 из 12», «пауза на 7 из 30», «дочитано» |

Голосом без модели: «прочитай выделенное», «пауза», «продолжай читать», «хватит читать», «останови чтение» —
это короткие фразы в `src/shortcuts/offline.js`.

## Как устроено

`src/voice/reader.js` — сеанс чтения:

- текст режется **по предложениям**, кусок не длиннее 300 символов; длинное предложение режется по запятым.
  Склеенные через пробел куски дают ровно прочитанный текст — ничего не теряется и не повторяется (тест);
- читает **в фоне**: инструмент сразу отвечает «читаю: 1 из 3», ход не занимается на минуты, поэтому пауза
  и стоп спокойно приходят следующим поручением;
- **пауза** обрывает звук (сигнал отмены убивает проигрывающий PowerShell) и запоминает номер куска;
  **продолжение** начинает этот же кусок. Прочитанные предложения не повторяются, оставшиеся не пропускаются.
  Если пауза пришлась на середину куска, он звучит заново целиком — точной остановки внутри wav нет;
- **сбой синтеза**: одна повторная попытка на том же куске, дальше — честная остановка с местом
  («чтение прервалось на 4 из 12: …»), а не «дочитано»;
- **длинный текст**: до 12 000 символов, дальше честно «дальше не читаю» с указанием полной длины;
- новое чтение заменяет старое: два голоса одновременно не говорят;
- имена файлов `.env*` не читаются, PDF и прочие форматы — честный отказ.

`src/tools/desktop.js` — инструмент `read_clipboard_aloud` получил действия и источники, чтение файлов
(`readDocumentText`), разбор html и docx, отказы с причиной. Старое деление `splitForSpeech` и `speakChunks`
оставлено как было: ими пользуются сценарии команд.

`main.js` — две небольшие связки: ответ не звучит поверх чтения (`readAloudBusy`) и аварийный стоп
прекращает чтение (`stopReading`). Диктовку С2 и голосовые режимы это не затрагивает: там свой сигнал и свой голос.

## Изменённые файлы

- `src/voice/reader.js` — новый: куски, пауза, продолжение, стоп, сбои;
- `src/tools/desktop.js` — действия и источники, чтение документов, разбор html и docx;
- `src/shortcuts/offline.js` — «прочитай выделенное» без Ctrl+C, фразы паузы и продолжения;

## Живая проверка на настоящем звуке

`node scripts/read-aloud-check.js` — речь синтезирует системный голос Windows («Microsoft Irina Desktop»)
в wav, проигрывает тот же код, что в продукте (`SpeechClient.play` → PowerShell SoundPlayer).

Результат последнего прогона:

- первый кусок прозвучал целиком — **8172 мс** настоящего звука через звуковое устройство;
- пауза пришлась на второй кусок: состояние `paused`, номер куска остался 1, звук прекратился;
- продолжение зазвучало **тем же куском** («Второе предложение…» второй раз), а не следующим и не с начала;
- стоп: после него ни одного нового куска, состояние `stopped`, чтение не занято.

Микрофон для этой проверки не нужен. Модель Silero в этой сборке не загружена (torch есть, модель не скачана),
поэтому живой прогон синтезировал системным голосом; путь проигрывания при этом настоящий, продуктовый.

## Ограничения

- **Точной паузы внутри фразы нет**: пауза повторяет текущее предложение с начала. Для длинных фраз это
  заметно на слух с секунду-две; лечится только своим проигрывателем с остановкой по позиции.
- **PDF не читается** (нет библиотеки разбора, ставить её без разрешения нельзя); docx читается.
- **Выделенное** берётся через UI Automation: в программах без текстового шаблона (некоторые игры,
  самописные окна) текст не отдаётся — тогда честный отказ «выделенного текста не видно».
- Чтение идёт в фоне, но **окно не показывает полосу «читаю»**: состояние есть в инструменте и в `snapshot()`,
  отдельной панели в интерфейсе пока нет (это следующий шаг, С3 не начат).
- Проверено на одном звуковом устройстве (HDMI-выход монитора). Наушники и другие выходы не проверялись.
