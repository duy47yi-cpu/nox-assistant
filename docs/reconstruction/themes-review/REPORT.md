# Проверка тем и эффектов фона

**Л1.** Снято 23 кадра настоящего окна Nox: 14 тем с градиентом и 9 эффектов. Размер каждого кадра — 1200×720; пустой чат, временный профиль и данные. Код не менялся.

Сводные листы: [темы](themes-contact.png), [эффекты](effects-contact.png). Эффекты сняты на тёмной теме с ожиданием 350 мс; это статичные кадры, поэтому движение не оценивается.

## Темы

| Тема | Наблюдение по кадру |
|---|---|
| Aurora | Бирюзовый градиент заметен в основном по краям и в промежутках; большая панель чата выглядит почти ровной. [Кадр](shots/theme-aurora.png) |
| Ember | Красно-янтарный фон слабо просматривается сквозь панели; центр выглядит почти сплошным бордовым. [Кадр](shots/theme-ember.png) |
| Рассвет (`dawn`) | Тёплый светлый фон читается; текст и элементы управления различимы. Явного дефекта не заметил. [Кадр](shots/theme-dawn.png) |
| Liquid | Тёмный сине-зелёный градиент сдержанный; волны заметнее у нижней части окна, местами рядом с полем ввода. [Кадр](shots/theme-liquid.png) |
| Liquid Day | Светлый градиент и нижние волны видны; контраст текста хороший. Явного дефекта не заметил. [Кадр](shots/theme-liquidday.png) |
| Frost | Холодный градиент очень мягкий, фон воспринимается почти ровным серо-голубым. [Кадр](shots/theme-frost.png) |
| Gradient | Фиолетово-синий градиент слабый; панели и общий фон близки по тону, поэтому цвет проявляется главным образом по краям. [Кадр](shots/theme-gradient.png) |
| Gradient Day | Пастельный фон заметен, композиция и текст читаются. Явного дефекта не заметил. [Кадр](shots/theme-gradientday.png) |
| Midnight | Почти чёрный фон воспринимается ровным; градиентное отличие от обычной тёмной темы слабо видно. [Кадр](shots/theme-midnight.png) |
| Neon | Неоновый характер сдержанный: сетка видна слабо, общий фон почти чёрный. [Кадр](shots/theme-neon.png) |
| Starry | Звёзды видны, фон сине-фиолетовый; элементы интерфейса различимы. Явного дефекта не заметил. [Кадр](shots/theme-starry.png) |
| Moonlight | Холодное пятно света и отличие градиента едва заметны; тема выглядит преимущественно ровной тёмно-серой. [Кадр](shots/theme-moonlight.png) |
| Sunrise | Тёплый оттенок виден в нижней области, но свечение выражено слабо. [Кадр](shots/theme-sunrise.png) |
| Glass | Фон почти ровный тёмно-серый, стеклянность панелей выражена слабо в пустом чате. [Кадр](shots/theme-glass.png) |

## Эффекты

| Эффект | Наблюдение по кадру |
|---|---|
| Звёзды (`stars`) | Точки видны на тёмном фоне; эффект различим. [Кадр](shots/fx-stars.png) |
| Волны (`waves`) | Линии заметны в нижней части окна, широкие и проходят под областью поля ввода; могут отвлекать. [Кадр](shots/fx-waves.png) |
| Снег (`snow`) | Точки видны, но в неподвижном кадре выглядят скорее редкой пылью, чем снегом. [Кадр](shots/fx-snow.png) |
| Дождь (`rain`) | Косые штрихи хорошо видны по окну; не закрывают основной текст. [Кадр](shots/fx-rain.png) |
| Узоры (`pattern`) | Топографические линии заметны, местами просвечивают под прозрачными поверхностями, включая поле ввода. [Кадр](shots/fx-pattern.png) |
| Лунный свет (`moon`) | На тёмном фоне пятно света почти не различимо. [Кадр](shots/fx-moon.png) |
| Зарево (`dawn`) | На тёмном фоне тёплое свечение почти не различимо. [Кадр](shots/fx-dawn.png) |
| Перелив (`drift`) | В статичном кадре изменение цвета практически не заметно; возможно, для оценки нужен более долгий просмотр движения. [Кадр](shots/fx-drift.png) |
| Сетка (`grid`) | Сетка у нижнего края очень слабая, заметна лишь при внимательном рассмотрении. [Кадр](shots/fx-grid.png) |

## Итог

Наиболее явные кандидаты на дальнейшую визуальную настройку: слабая заметность градиента у **Frost, Gradient, Midnight и Moonlight**; слабая заметность эффектов **moon, dawn и grid**. Для `drift` статичного кадра недостаточно — нужно оценить в живом окне. Это только перечень наблюдений; правки не вносились.
