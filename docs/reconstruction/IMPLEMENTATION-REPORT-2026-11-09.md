# Nox — реализация первого экрана: отчёт (09.11.2026)

> Задача: реализовать первый рабочий экран Nox по `docs/reconstruction/` с максимальным визуальным сходством, не ломая существующее приложение.
> Этот файл — честный отчёт: что сделано, чем проверено, что совпадает, что не совпадает и почему.

## 1. Что сделано

**Новый экран Nox** — `renderer/index.html` (`<section class="view view-nox" data-view="nox">`), по умолчанию открывается при запуске:

- Окно 1200×720 (`useContentSize`), без системной рамки, прозрачное, со скруглением 12 px, тень окна нативная.
- Рейка 52 px (46 px при ширине ≤1000 px), только иконки, активный пункт с полосой 4×22 и мягкой заливкой.
- Панель истории 244 px (176 px в узком окне): заголовок «История», кнопка «Новый чат», группы «Сегодня» / «Ранее» по `updatedAt`, строки с «…» (закрыть чат), пустое состояние.
- Центральный чат: лента настоящей беседы (те же сообщения, поток, шаги, ошибки, подтверждения из `app.js`), пузырь пользователя справа, ответ без пузыря с меткой `NOX`, живая строка «Ход работы · Выполняется · 0.0 с» → «Готово · 0.0 с», автоскролл к низу.
- Панель сферы 360 px (278 px): заголовок `☀ — ⛶ ×` (оформление/свернуть/развернуть/закрыть — работают через новый канал `window:control`), холст сферы.
- Поле ввода-капсула: textarea, строка инструментов (скрепка, режим, выбор «Быстрая/Умная · обдумывание» справа, микрофон, синяя круглая отправка), осциллограмма — только во время настоящей диктовки.
- Анимации по `animation-timeline.md`: появление сообщений 200 ms ease-out, рабочая строка 180 ms, фокус композера 200 ms, состояния сферы, hover/press у кнопок. Учитываются `prefers-reduced-motion` и `html[data-motion="off"]`.

**Два варианта сферы** — `renderer/orb-nox.js`, без новых зависимостей (Canvas 2D, не Three.js — установка пакетов не требовалась):

- `wire` — проволочная сфера из референса: ~112 меридианов × 54 параллели, затемнение дальней полусферы, яркий пояс ниже экватора, непрерывная деформация ±6–8 % при неподвижном центре, без вращения.
- `nox` — точечная сфера с ядром по `orb-spec.md`: 1400 точек Fibonacci + ~200 точек ядра, аддитивное свечение, объёмное ядро 0.42R, дыхание 1.8 с, медленное вращение 0.08 рад/с, сдержанный ореол, 8 состояний (idle/attentive/listening/thinking/speaking/waiting_approval/error/success).
- Переключение **только для разработки**: `window.NoxScreen.setVariant('wire'|'nox')`, `localStorage.noxOrb`, URL `#orb=wire` или Ctrl+Alt+O. В пользовательском интерфейсе переключателя нет.

**Сохранение прежних функций.** Ни один раздел не удалён: команды, история, подключения, настройки, аккаунт, дела, столы, миссии, ожидание подтверждений работают как раньше. Классический экран (прежняя главная со сценой, подсказками, столами и миссиями) остался целиком и открывается из Настройки → Вид → «Классический экран» → «Открыть». Чат и поле ввода физически переносятся между экранами (`nox-screen.js`), поэтому логика беседы не дублируется. Приложение стартует видимым (раньше окно создавалось скрытым — для показа первого экрана это изменено осознанно).

**Совместимость с прежним.** React не добавлялся: существующий стек — ванильный HTML/CSS/JS, миграция не оправдана. Новые пакеты не ставились. Добавлено только поле `updatedAt` в `ChatBook` (для групп «Сегодня/Ранее») и канал `window:control` в `main.js`/`preload.js`.

## 2. Как проверено

- **Настоящий запуск Electron.** `electron .` с временным `NOX_DATA_DIR` — окно 1200×720 появляется на рабочем столе (снимок рабочего стола `desktop`-проверки делался отдельно, окно видно). Скриншоты экрана снимались скриптом `scripts/nox-shot.js`, который поднимает **настоящее приложение** (`require('../main')`) с временным профилем и данными и делает `capturePage()`.
- **Скриншоты** — 1200×720 и 864×520, DPR 1, без ошибок консоли (проверено через CDP: `consoleErrors: []` у всех пяти снимков).
- **Тесты:** `node --test` в `apps/jarvis-desktop` — **2115 из 2115** (включая `project-map`, `chats`, `orb-a11y` и др.), в `apps/nox-server` — **31 из 31**.
- **Живые проверки в настоящем окне:** отправка сообщения через API-заглушку (появились пузырь, живой таймер «Ход работы · 3.9 с», ответ, состояние вернулось в idle), переключение чатов из истории, «Новый чат», сворачивание/разворачивание окна, кнопка «Оформление» (открывает Настройки → Вид), переключение wire/nox, переход на классический экран и обратно.

## 4. Геометрия (измерено в настоящем окне)

1200×720: окно 1200×720, рейка x9 52×702, история x69 244×702, чат x321 502×702, сфера x831 360×702, холст сферы 332×332 (сфера ~280 px = 23.3 % ширины окна, центр на 50.8 % высоты), композер 476×82.

864×520: рейка 46, история x63 176×502, чат x247 322×502, сфера x577 278×502, холст 240 (сфера ~202 px), композер 296×82.

Это соответствует `design-tokens.md` §5 и `component-spec.md` (§2–§6), кроме композера (82 px против 76 в спеке) и холста сферы (332 px вместо 260 — так сфера совпадает с референсом по доле окна 23.4 %, а не по абсолютному canvas).

## 5. Сфера

- `wire`: плотность 112×54 (измерено по `02-sphere-2x.png`, в спеке «60×40 ячеек» — оценка вниз), затемнение дальней полусферы, яркий пояс, деформация ±6–8 %, центр неподвижен, вращения нет. Средние цвета внутри сферы близки к референсу (наши avg (32,74,94) / p90 75 / p99 113 против (41,81,101) / p90 99 / p99 119).
- `nox`: по `orb-spec.md`; ядро видно, объём читается, ореол сдержанный. Это авторский вариант Nox, пиксельное совпадение с проволокой не требуется и не заявляется.
- Производительность (Electron на этой машине): 260×260 dpr1 — wire 178 fps, nox 176 fps; 300 px dpr 1.73 — nox 176 fps, wire ~50 fps (в программном композитинге без GPU; при реальном DPR 1 на этой машине — 178 fps). Пауза в фоне, reduced-motion, DPR — учтены.
- Анимация доказана: кадры через 700 мс различаются на 125 149/270 400 px (wire) и 77 399/270 400 px (nox); при `data-motion="off"` — 0 px.

## 6. Кнопки и что реально работает

Работают (проверено в живом окне): «Новый чат», выбор чата в истории, закрытие чата через «…», отправка сообщения (Enter и кнопка), остановка хода, микрофон (при включённой диктовке; без неё честно объясняет, что включить), выбор «Быстрая/Умная» и глубины обдумывания, кнопки окна (свернуть, развернуть, закрыть в трей), «Оформление» (открывает Настройки → Вид), переключение на классический экран и назад, Ctrl+1/2/3/4/5, Ctrl+L, Esc-стоп.

Не имитируется: осциллограмма показывается и анимируется только при настоящей диктовке; строка «Ход работы» тикает от реальных событий ядра; сфера меняет цвет/скорость от настоящего состояния.

## 7. Что осталось визуально не совпадающим (и почему)

1. **Строка «Ход работы · Выполняется 10.4 с» в кадре референса.** На статичном снимке её нет: это живое состояние реального хода, а не свойство экрана. Формат строки реализован и проверен в живом окне (например, «Готово · 3.9 с»), но подделывать её в фикстуре мы не стали. Из-за её отсутствия видимая верхняя строка в кадре 864×520 сдвинута на ~40 px относительно референса (обрезана верхняя строка).
2. **Сфера wire.** Наша — регулярный глобус с ровным поясом; в референсе сетка сильнее деформирована, размыта видеокодеком и даёт муар. Тон близок, форма нет. Вариант `nox` оценивается по своей спецификации, не по пиксельному совпадению.
3. **Рейка.** В референсе 6 иконок (лого, дом, ×, шестерёнка, история, аватар). У нас 7 (лого, чат, команды, история, подключения, настройки, аккаунт) — добавлены рабочие разделы приложения, которые нельзя было потерять. Иконки по смыслу другие.
4. **Поле ввода.** Пилюля показывает честный текст «Быстрая · думает кратко» вместо «Гибрид»; второй значок — «объясни, что я обвёл» (рабочая функция), а не треугольник режима; ширина/высота 82 px против 76.
5. **Ответ ассистента.** Нет кнопки «копировать» под сообщением (в коде приложения такой функции нет; добавлять имитацию не стали), метка `NOX` вместо `JARVIS`, нет подписи `BY AMBIONYS` (по брифу не воспроизводится).
6. **Пустой экран.** В референсе рейка и чат — одна панель (история скрыта), у нас рейка отдельная колонка (история скрыта, чат расширяется). Пропорционально близко, но геометрия левого края другая.
7. **Мелкое:** история в референсе чуть плотнее (33–34 px против 36), у нас нет нативных подсказок macOS, шрифт Inter вместо возможного Segoe; заголовок пустого экрана 22 px.

## 9. Как запустить и как переключать вариант сферы

```
cd apps/jarvis-desktop
npm start
```
Первый экран — Nox. Классический: Настройки → Вид → «Классический экран» → «Открыть».

Для разработки: `window.NoxScreen.setVariant('wire'|'nox')` в консоли, `localStorage.setItem('noxOrb','wire')` до перезапуска, URL-фрагмент `#orb=wire` или Ctrl+Alt+O. В интерфейсе переключателя нет.

Снимки: из `apps/jarvis-desktop` (снять `ELECTRON_RUN_AS_NODE`):
```
.\node_modules\electron\dist\electron.exe scripts\nox-shot.js --out ..\..\docs\reconstruction\screenshots\nox-1200x720-full-wire.png --width 1200 --height 720 --state full --orb wire
node scripts\nox-compare.js --mode side --original ..\..\docs\reconstruction\muse\01-chat-full.png --impl ..\..\docs\reconstruction\screenshots\nox-864x520-full-wire.png --out ..\..\docs\reconstruction\screenshots\compare-01-chat-full-wire-864.png --height 520
```

## 10. Оценка готовности

- **Экран как оболочка и чат: ~85 %** — геометрия, токены, панели, композер, история, реальный чат и кнопки в порядке; расхождения — рейка-надмножество, пилюля режима, отсутствие кнопки копирования, детали типографики.
- **Сфера wire: ~65 %** — тон/цвет/пояс/деформация есть, но плотность и «мягкость» референса не достигнуты; nox-вариант — ~90 % от своей спецификации.
- **Совпадение кадра целиком (864×520):** структурно высокое, пиксельно — нет (другая рейка, другое окно, живая строка отсутствует). Доля изменённых пикселей 60 % — это метрика отличий, не точность.
- **Готовность к показу владельцу:** да, как первый рабочий экран с честными ограничениями выше. Коммит не делался (правило: только по просьбе владельца).

Следующие шаги (этап 2, не делались): кнопка копирования ответа, плотнее сетка wire и мягче пояс, единая панель рейка+чат в пустом состоянии, «Гибрид»-подобный компактный селектор режима, кадры с реальным состоянием «Выполняется» для сравнения, второй экран.
