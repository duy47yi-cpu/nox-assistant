# Риски внедрения

## 1. Риски доказательства

| Риск | Почему | Что делать |
|---|---|---|
| Принять макет за работающую функцию | Агент, MCP-орбита, память, календарь показаны в V02/V03 нарисованными окнами чужих программ; V03 прямо пишет «Скоро» | Брать из них только **вид и порядок состояний**. Поведение Nox определяет его ядро (`decide`, `verify`), а не ролик |
| Принять монтаж за анимацию | Наплывы, наезды, склейки тем, подсветка курсора | Пользоваться только M01–M09 (`MOTION-ANALYSIS.md`). Остальное — дизайнерское решение, а не «как у Luxify» |
| Смешать поколения G1–G4 | Шрифт, рейка, размеры, переключатели разные | Каждое число в `DESIGN-TOKENS.md` помечено поколением |
| Цвета из видео | Сжатие H.264 сдвигает цвета на несколько единиц | Точные значения есть только в полях интерфейса (#4466FF, #0A0A0A). Остальные — ориентир |
| Размеры в «пикселях экрана» | Масштаб записи V08 оценён (0.6), масштаб снимков неизвестен | Использовать **доли окна** (рейка 8–15%, колонка 43–44%, сфера 40–46%), а не пиксели |
| Реакция сферы на голос | Настройки есть, видимой реакции нет | Не утверждать «как у Luxify». Числа для Nox подбирать на своей сфере |

## 2. Технические риски для Nox

| Риск | Где в Nox | Опасность | Снижение |
|---|---|---|---|
| Ослабить разрешения ради «красивой» карточки агента | `src/policy/modes.js` (`decide`, `hardDeny`), `src/policy/approvals.js` | **Высокая**: подтверждение станет декоративным | Менять только отображение. Тесты `node --test` на политику не трогать. «Разрешить» — тот же `approval:respond` |
| Показать «выполнено» по словам модели | Плашки шагов в чате | Нарушение правила проекта | Плашка «выполнено» — только при `verify` / `checkEffect` = успех; иначе честное «не проверено» |
| Показать имя модели или провайдера | Чат, настройки ИИ | Нарушение правила проекта | Только «Быстрая» / «Умная» |
| Оверлей-аватар | Новое окно Electron без рамки | Перехват мыши, лишняя нагрузка на видеокарту, мешает играм | `setIgnoreMouseEvents`, лимит FPS, автоскрытие в полноэкранных, выключено по умолчанию |
| Захват звука системы для сферы | Нет в Nox | Нужны системные API; приватность | Сначала только голос самого Джарвиса (`src/voice/tts.js` уже знает, когда говорит) |
| Сфера за краем окна | `nox-screen.css` сетка 1200×720 / 864×520 | Сломать проверки `scripts/nox-shot.js`, `nox-qa-verify.js` | Обновить снимки-эталоны вместе с изменением |
| Вкладки столов на экране Nox | `renderer/desks.js`, `desks:*` | Две точки входа к одним данным | Одна модель (`src/desks/store.js`), два вида |
| Контекстное меню команд | `renderer/app.js` | «Удалить» без подтверждения | Удаление через существующий путь с подтверждением; экспорт — только безопасный (без секретов) |
| Эффекты частиц на фоне | CSS/Canvas | Нагрузка, мелькание | Уважать `motion` и `prefers-reduced-motion`; пауза в фоне, как у `orb-nox.js` |
| Светлые темы экрана Nox | `themes.css` + `nox-screen.css` | Нечитаемый текст | Тест `renderer/themes.test.js`, контраст ≥ 4.5:1, как в `accent.js` |
| Работа других агентов в репозитории | Незакоммиченные изменения в `apps/jarvis-desktop` (см. git status) | Конфликты | Начинать внедрение с `git status` и работать узкими изменениями |

## 3. Юридические и продуктовые риски

| Риск | Что нельзя переносить |
|---|---|
| Бренд | Логотип (облачко на синем круге), имя Luxify, «Luxify Connect», «Snapse», «Luxify PC Control» |
| Фирменный знак сферы | Ровно 5 плоских кругов, срезанных краем, в том же синем. Сфера Nox — точечная, её и развивать |
| Чужие произведения | Арт-серия с картинами (в т. ч. «Звёздная ночь»), обложки голосов с логотипами Marvel, Portal, Atomic Heart |
| Голоса персонажей | Jarvis, Friday, GLaDOS, Karen, Edith, Ultron, Vision и т. п. |
| Тексты | Подписи и рекламные формулировки дословно |

## 4. Порядок, который меньше всего ломает

1. Только F-изменения: плашки шагов, номер шага в строке хода, композиция Главной, сброс раздела настроек.
2. S-изменения с тестами: подтверждение в строке хода, контекстное меню, вкладки столов.
3. B-изменения отдельными задачами: оверлей-аватар, звук для сферы, «Сохранить как команду».

После каждого шага — `node --test` в `apps/jarvis-desktop` и `apps/nox-server` и проверка настоящим окном (правило `AGENTS.md`).
