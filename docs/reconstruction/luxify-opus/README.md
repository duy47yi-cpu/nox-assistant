## Обозначения

- **[В]** — видно в материале. **[О]** — оценено по кадрам или числам. **[П]** — предложение, не доказано.
- **G1** — версии 1.x (рейка из значков, «ОСНОВНОЕ ОКНО»); **G2** — 2.0; **G3** — 2.2 (столы, агент); **G4** — 2.4 (стили, плагины).
- **A / B / C** у экранов — запись приложения / ролик / нарисованный макет.
- Пиксели V07/V08 — пиксели видео 1280×720, не экрана.

## Как повторить

Скрипты в `metadata/scripts/` (Python 3.13, OpenCV, Pillow, NumPy, faster-whisper; всё уже стояло на компьютере). Пути к источникам заданы внутри скриптов.

```bash
python -I metadata/scripts/curve.py "C:/Users/abdut/Downloads/luxify/video_2026-11-10_22-12-47.mp4" out.csv
```
