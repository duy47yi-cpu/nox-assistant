# Сопоставление с Nox

Код Nox читался только для сверки (`AGENTS.md`, `renderer/nox-screen.css`, `renderer/nox-screen.js`, `renderer/orb-nox.js`, `renderer/themes.css`, `main.js`). Ничего не менялось.

Что Nox сохраняет обязательно: Electron, работающий чат, команды, MCP, сохранённые настройки, журнал, систему разрешений (`src/policy/`), работу агента, **свою точечную сферу** (`renderer/orb-nox.js`: варианты «проволока» и «точки с ядром», `setVoice(0..1)`).

Сложность: **Н** низкая (часы), **С** средняя (дни), **В** высокая (неделя и больше). Риск поломки: **н / с / в**.
Слой: **F** — только интерфейс; **S** — меняется состояние интерфейса или настройки; **B** — нужен новый код ядра; **?** — данных не хватает.

## Итог по слоям

- **Только интерфейс (F)**: композиция со срезанной сферой, плашки шагов в чате, вид дерева команд, колонка описания в выборе действия, поиск и сброс в настройках, проверка светлых тем, строка расхода. Около 60% строк таблицы.
- **Меняется состояние интерфейса (S)**: вкладки столов на экране Nox, контекстное меню команд, номер шага и «Стоп» в строке хода, подтверждение внутри строки хода.
- **Нужно новое в ядре (B)**: аватар-оверлей на рабочем столе с автоскрытием; захват звука системы и приложений для сферы; «Сохранить ход как команду»; фраза смены стола; оверлеи плагинов.
- **Данных не хватает (?)**: отдаёт ли распознавание Windows промежуточный текст для «живой» строки; как сфера Luxify реагирует на звук в числах; как ведут себя «Отклонить» и «Стоп» у агента.

## Где Nox уже сильнее показанного

- Подтверждение и проверка результата действительно работают (`decide`, `approvals`, `checkEffect`). У Luxify агент показан только макетом и как «скоро».
- Отмена подтверждения фразой и авто-отмена через 30 с (`src/policy/approvals.js`). У Luxify этого не видно.
- Своя точечная 3D-сфера с состояниями `verifying / success / cancelled`. У Luxify сфера плоская из 5 кругов.

## Чем Nox не должен стать

Не нужно переносить логотип, имя «Luxify», вид колец, голоса-подражания персонажам фильмов и игр из каталога Luxify (Jarvis, Friday, GLaDOS, Karen и др. — имя «Джарвис» у Nox своё, речь только о чужих голосах и обложках), арт-серию с картинами, рекламные счётчики. Переносятся принципы: один акцент на всё, якорь-сфера, короткие плашки шагов, подтверждение «что уйдёт», понятные состояния.
