# Временные шкалы видео

Для каждого видео сделаны: раскадровка по 1 кадру в секунду (`storyboards/V0N-*-1fps.jpg`), кривая изменений по кадрам (`metadata/V0N-curve.csv`: средняя разница соседних кадров, серые 320 px) и ключевые кадры в исходном разрешении (`frames/V0N-t…`). Места с движением просматривались плотнее, до отдельных кадров (`storyboards/` с диапазоном времени в имени).

Резких склеек почти нет: детектор сцен ffmpeg с порогом 0.25 нашёл одну в V04 (36.73 с) и одну в V08 (41.93 с — открылся системный диалог). Ролики V01–V06 переходят между сценами наплывами, размытием и движением камеры. Поэтому границы сцен ниже ставились по раскадровке и кривой.

Запись: `Время → Что видно → Доказательство → Достоверность`. [В] — видно в материале. [О] — оценено по кадрам. [П] — предположение.
**Монтаж** — эффект ролика, не приложения.
