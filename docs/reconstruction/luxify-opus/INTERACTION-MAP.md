# Карта взаимодействий

Формат: `Было → Действие пользователя → Ответ приложения → Стало`.
Группы: **Н** — наблюдалось в сырой записи или по кадрам ролика, где видно и действие, и ответ; **В** — вероятно (видно состояние до и после, но не действие или наоборот); **С** — скрытая логика, которую материал не показывает.

## Как пользователь возвращается назад

- По рейке — всегда (N1).
- Из формы команды — «Отмена» или вкладка «Редактировать» (V07, IMG10).
- Из модальных окон — «✕», «Закрыть» или «Отмена» внизу (IMG11, IMG13, V07, V08).
- Esc в модальных окнах — **не показан**.

## Как показаны ошибки и разрешения

- Ошибка распознавания — плашка в чате (I2).
- Разрешение на опасный шаг агента — в самой карточке агента, с текстом того, что уйдёт (G3).
- Подтверждение запуска команды — карточка поверх окна (C14).
- Сетевые ошибки, ошибки ключа, ошибки установки пака — **в материале нет**.
