# Экраны и состояния Luxify

Найдено **44 экрана, диалога и состояния**. По силе доказательства:

- **A — запись настоящего приложения** (сырые V07/V08 или чистый снимок экрана): 18.
- **B — экран приложения в рекламном ролике** (наклон, наезды, склейки, но интерфейс настоящий) [О]: 17.
- **C — нарисованный макет или графика ролика**, работа не доказана: 9.

Размеры даны в пикселях источника. Для G1 в V08 масштаб к экрану ≈ ×1/0.6 [О]. Для G2 использован IMG04 (снимок, масштаб неизвестен).

## Карта экранов

```
Окно (рамки нет, свои кнопки ─ □ ✕)
├─ Рейка: логотип · Главная · Команды · Дополнения · [Расширения G3] · [Умный дом G4] · [Luxify AI] · Настройки … Свернуть · Аккаунт
├─ Главная ─────────── G1: История команд + Панель управления + сфера
│                     G3/G4: вкладки столов + сетка виджетов + сфера ─→ правка сетки ─→ «Новый стол»
├─ Команды ─────────── дерево ─→ контекстное меню
│                     └→ форма команды ─→ «Список/Добавить действие» · автодополнение · «Запись действий» · «Создать с помощью AI»
│                     └→ подтверждение запуска
├─ Дополнения ──────── вкладки (Плагины | Паки команд | Команды | Озвучка | Оформление) ─→ карточка ─→ диалог настроек плагина
├─ Luxify AI ───────── список чатов + разговор ─→ «Настройки Luxify AI» (окно)
├─ Настройки ───────── поиск + разделы ─→ палитра цвета · диалог файла ОС
├─ Аккаунт
└─ Вне окна: аватар на рабочем столе · голосовая строка [C] · карточка агента [C] · Островок · круговое меню Snapse/Конвертер · история буфера · питомец · Telegram-бот · пульт в телефоне
```
