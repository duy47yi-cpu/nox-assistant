# Конечные автоматы

Восстановлены только там, где состояния видны. Переходы со знаком **(?)** не показаны: это логичное дополнение [П], а не свойство Luxify.

## 1. Карточка хода агента (макет V02, V03)

```
            голос/текст поручения
   [нет] ───────────────────────────► [plan]  «Составляю план…»  ● синяя
                                         │
                                         ▼
                                      [act k/N]  «Шаг k из N · Нажимаю «…»»  ● синяя, обводка цели
                                         │  ▲ следующий шаг
                                         │  └──────────┐
                     шаг с отправкой     ▼             │
                                      [await]  «Жду вашего разрешения» + что именно уйдёт
                                         │  «Разрешить»            «Отклонить» (?)
                                         ▼                               ▼
                                      [done]  «✓ Готово»  ● зелёная    [denied] (?)
                                         │
                       «Сохранить как команду»
                                         ▼
                                      [saved]  кнопка зелёная

  «■ Стоп» доступна в plan / act / await ──► [stopped] (?)   — кнопка есть, результат не показан
```

Видно [В]: plan, act с номером шага, await с текстом отправки, done, saved, кнопка «Стоп» во всех состояниях, «Шаг N» в шапке.
Не видно: отказ, остановка, ошибка, повтор шага, таймаут ожидания.

## 2. Голосовой ввод (V06, IMG02, IMG04, IMG12)

```
 [mic off] ──щелчок по микрофону──► [listening]   кнопка акцентная
     ▲                                  │ услышано имя «Джарвис»
     │                                  ▼
     │                              [wake]  плашка «Джарвис» в строке
     │                                  │ распознавание идёт
     │                                  ▼
     │                              [transcribing]  текст дописывается, точки уровня
     │                                  │ конец фразы
     │                  ┌───────────────┴──────────────┐
     │                  ▼                              ▼
     │            [matched]                     [not understood]
     │            команда выполнена:             «🎤 Речь не распознана.»
     │            «Выполнено ✓» в Истории        (IMG12)
     └──────────────────┴───────────── снова [listening]
```

На Главной есть «Режим префикса» и «Тихий режим» [В]. Как они меняют автомат — не показано. По названию [П]: «префикс» — слушать только после имени, «тихий» — без голосовых ответов.

## 3. Строка дерева команд (V07)

```
 [обычная] ──щелчок──► [выбрана: синяя + ✎ ⏻ 🗑]
     ▲                    │ ⏻                 │ ✎ / двойной щелчок
     │                    ▼                   ▼
     │              [отключена: тусклая]   [форма команды]
     │                    │ ⏻ (?)            │ «Отмена» / «Сохранить»
     └────────────────────┴──────────────────┘
 Любое изменение ──► кнопка «Сохранить» акцентная (dirty) ──«Сохранить»──► обычная (?)
```

Ветки: свёрнута ⇄ раскрыта (шеврон, ≤ 33 мс).

## 4. Форма команды

```
 [пустая форма] ──«Действие»──► [Список действий] ──«Вставить»──► [шаг добавлен]
        │                                     └── «Добавить пустое действие» ──► [пустой шаг]
        ├──«Запись действий»──► [запись: таймер] ──«Стоп и добавить»──► [шаги из записи]
        │                                          └── «Отменить» ──► назад
        └──«Создать с помощью AI»──► [описание] ──«Собрать»──► [план N шагов]
                                                               ├── «Уточнить…» ──► [план]
                                                               ├── «Назад»
                                                               └── «Вставить в команду» ──► [шаги]
```

## 5. Настройки (V08)

```
 [чистые] ──изменение──► [dirty: «Сохранить» акцентная]
   ▲                         │ «Сохранить» (?)        │ ↻ у раздела (?)
   └─────────────────────────┴────────────────────────┘
 Поиск: [все разделы] ⇄ [отфильтровано по подписям]
 Цвет: [образец] ──щелчок──► [палитра: предпросмотр вживую] ──«Готово»/«Отмена»(?)──► [образец]
```

## 6. Аватар на рабочем столе (настройки V08, вид V06, IMG14)

```
 [выключен] ──«Включить аватар»──► [виден: дыхание в покое]
                                       │ источник звука даёт уровень (настройка)
                                       ▼
                                   [реагирует] (?)  — заявлено, не показано
                                       │ полноэкранная программа + «Автоматически скрывать»
                                       ▼
                                   [скрыт] ──выход из полноэкранного (?)──► [виден]
 Положение: сетка 3×3 · перетаскивание (если включено) · «Закрепить положение»
```

## 7. Окно приложения

```
 [развёрнутая рейка] ⇄ «Свернуть» ⇄ [свёрнутая рейка]
 [тёмная тема] ⇄ [светлая тема]      акцент: 8 образцов + свой HEX
 размер окна: свободный (минимум не показан)
```
