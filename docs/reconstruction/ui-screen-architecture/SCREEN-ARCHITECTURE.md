# Структура экранов Nox

Один каркас окна и самостоятельные экраны внутри него. Классический экран (`dialog`) остаётся как был: это отдельная настройка владельца.

```
┌──────────────────────────────────────────────────────────────┐
│ ◐ NOX                                  ⚙  ◯  │  –  ⤢  ✕     │  общая шапка 40 px
├────┬─────────────────────────────────────────────────────────┤
│ 💬 │                                                         │
│ ⚡ │            рабочая область раздела                      │
│ ✓  │         (своя раскладка у каждого)                      │
│ 🔌 │                                                         │
└────┴─────────────────────────────────────────────────────────┘
 рейка 52 px (46 px до 1000 px): только разделы
```

## Общее для всех разделов

| Часть | Где | Что |
|---|---|---|
| Шапка `#noxTopbar` | `index.html`, стили `nox-shell.css`, кнопки окна `nox-shell.js` | Бренд NOX слева. Справа «Настройки» (`data-nav="settings"`, точка-напоминание), «Аккаунт» (`data-nav="account"`), разделитель, «Свернуть / Развернуть / Закрыть». Вся шапка — область перетаскивания окна, кнопки — `no-drag`. |
| Рейка `.rail` | `index.html` | Чат (Ctrl+1), Команды (Ctrl+2), Журнал (Ctrl+3), Подключения (Ctrl+4). Настройки (Ctrl+5) открываются из шапки и по клавише. Во всех разделах, включая чат, рейка — отдельная панель с зазором 8 px (раньше в чате она сливалась с историей). |
| Активный раздел | `show()` в `app.js` | `aria-current="page"` на всех `[data-nav]` раздела: в рейке — полоса и подсветка, в шапке — подсветка кнопки настроек или профиля. |
| Токены | `nox-shell.css` | Те же значения, что в `nox-screen.css`: фон `#0F0F10`, панели `#18181B`, граница `#2A2A2E`, текст `#F1F1F3/#9A9AA0`, акцент `#2E9AC1`, Inter. |

Настройки не дублируются: в рейке кнопка осталась в разметке (её использует классический экран), но в разделах Nox она скрыта. Кнопки окна — один набор на окно.

## Экраны

| Раздел | Рабочая область | Что видно |
|---|---|---|
| **Чат** | История 244 px · Лента и поле ввода · Сфера 360 px (400 px на широком) | Одобренная композиция. История сворачивается кнопкой в её шапке, открывается кнопкой в шапке чата; выбор запоминается (`localStorage noxHistCollapsed`). До 1000 px история по умолчанию скрыта и выезжает поверх ленты: закрывается Esc (Esc при этом не останавливает ход), щелчком мимо или выбором чата. Сфера без изменений (`orb-nox.js` не тронут). |
| **Настройки** | Панель раздела: категории, поиск и чипы слева · параметры справа | Нет истории, поля ввода, сферы. До 1000 px категории — лента над параметрами, все шесть помещаются. |
| **Команды** | Каталог (вкладки, поиск, запись, импорт/экспорт) и «Готовые паки» · редактор на всю панель | Без изменений внутри, кроме удалённых дублей кнопок окна. |
| **Подключения** | Поиск и фильтры · список · «Популярные» | Без изменений внутри, кроме удалённых дублей кнопок окна. |
| **Журнал** | Заголовок «Журнал» · фильтры статусов и поиск · таблица на всю ширину | Переведён в систему Nox. Статусы и их тексты — прежние (`statusBadge` в `shared.js`): «Не проверено» не выдаётся за «Подтверждено». |
| **Аккаунт** | Заголовок · карточка входа / лимитов в ширину чтения (760 px) | Переведён в систему Nox, содержимое из `account.js` прежнее. |
| **Дела** | Заголовок · группы дел | Переведены в систему Nox, логика прежняя. |

## Размеры окна

| Окно | Чат | Остальные разделы |
|---|---|---|
| 1600×900 | история · лента · сфера 400 | полная раскладка |
| 1200×720 | история 244 · лента · сфера 360 | полная раскладка |
| 864×520 | рейка 46 · лента · сфера 278, история выезжает | шапки разделов 56 px вместо 72, вторичные колонки уходят под основную (как и раньше в слоях разделов) |

Горизонтальной прокрутки страницы нет ни на одном размере, видимые кнопки не перекрыты (проверка `LAYOUT_JS` в `scripts/nox-screens-shot.js`).

## Состояние при переходах

Переход — только `show()` из `app.js`, его логика не менялась. Лента и черновик остаются в DOM, активный чат не меняется, категория настроек и фильтры — в своих модулях. Навигация не вызывает `chat:send` (счётчик в скрипте проверки).
