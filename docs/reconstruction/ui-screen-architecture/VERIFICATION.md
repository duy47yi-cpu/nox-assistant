## Что не проверено

- Светлые темы и свой акцент: разделы Nox (как и раньше в `nox-*.css`) рисуются тёмной палитрой Nox независимо от темы. Это не менялось.
- Показ подтверждения поверх нового каркаса и Esc в выехавшей истории во время настоящего хода: в заглушке ход длится миллисекунды. По коду: Esc перехватывается только когда история выехала; в остальное время «стоп» работает как раньше.
- Перетаскивание окна за шапку и разворот двойным щелчком: проверены только по CSS (`-webkit-app-region`), мышью не таскали.
- Классический экран (`dialog`) не снимался: его разметка и стили не менялись, общая шапка на нём скрыта.
