## Выбор и параметры действия

[П] Диалог 640×520: заголовок h60 и крестик; поиск h40; тело — категории 150 и список остатка; низ h64 с «Отмена» и «Добавить». Один клик выбирает строку, двойной клик или Enter добавляет; Escape отменяет; без выбора «Добавить» недоступна. При пустом результате — «Ничего не нашлось». Список строится из `tools:catalog` и текущего фильтра редактора. Сейчас `EDITOR_STEP_TOOLS`: `app_open`, `ui_keys`, `wait`, `speak`, `volume_set`; категории [П] «Все», «Программы», «Клавиши», «Время», «Голос», «Звук». Не предлагать действия мыши и отправку из рекламы, если их нет в каталоге редактора. После выбора вставить шаг и показать параметры; фокус — первое обязательное поле.

Текущий JavaScript устанавливает `MAX_STEPS = 20` и заменяет начальную статическую подпись HTML `0 / 10` при отрисовке; предел интерфейса и хранилища — 20. Имя в поле до 60 символов, фраза до 80, папка до 60, горячая клавиша до 40; не изменять эти пределы молча. Для примера: `app_open.name` обязательно (до 260), `ui_keys.keys` обязательно и `window` необязательно, `wait.ms` — целое 0–10000, `speak.text` — до 300, `volume_set.percent` — целое 0–100. Фактические схемы из каталога остаются источником истины.

Поля строятся из `parameters.properties/required`: число с min/max/step, boolean-переключатель, enum-список, длинный текст — многострочное поле, остальное — текст; подсказка и диапазон рядом. При замене типа текущий `stepNode` сохраняет лишь общие параметры; [П] предупредить перед потерей непустых. Неизвестный тип старого шага отображать с исходными параметрами и отметкой «инструмент недоступен»; не отбрасывать незаметно. Схема сервера — источник истины.

## Совместимость

`renderer/app.js`: `newCommand`, `selectCommand`, `confirmLeave`, `renderSteps`, `saveDraft`, `runCommand`, `startRecording`, `pickCommandsImport`; `renderer/cmd-steps.js` — перестановка/описание; `src/commands/store.js` — схема v2, атомарная запись; `runner.js` — политика и проверка; `src/workspaces/commands.js` — пространство. Текущий `saveDraft` формирует ограниченный payload; `store.js` сохраняет существующие `collections` и `optionalPhrases`, когда поля отсутствуют. Сохранение неизвестных типов и старых версий требует проверки, не считать гарантированным. Другие риски: потеря аргументов, горячих клавиш, предупреждений, подтверждений и неверный успех.
