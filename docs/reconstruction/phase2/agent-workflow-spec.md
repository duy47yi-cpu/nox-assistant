# Журнал и ход агента

[В] V2 00:09–14 и V3 00:06–20 показывают рекламные плашки шага, разрешения и ошибки; это не свидетельство полного плана в Nox. См. `video-analysis.md`. Ниже [П] Nox; общий каркас — `navigation-map.md`.

## Журнал действий

1200×720: заголовок x80,y72; поиск x80,y128,w360,h40 и «Обновить» справа; фильтры y180,h40: «Все», «Подтверждено», «Не проверено», «Провалено», «Ошибки», «Отклонённые». Таблица x80,y232,w1092: время 120, действие около 300, риск 90, статус 150, итог — остаток; заголовок 40, строки min56. При 864 фильтры прокручиваются горизонтально, строки становятся вертикальными карточками с теми же подписями. Счётчик «Показано N из M». Без данных — «Журнал пуст»; фильтр без совпадений — «Ничего не нашлось»; сбой — причина и повтор. Поиск применяется к загруженным последним записям, как `reloadJournal/renderJournal` в `renderer/app.js`; не обещать поиск по всей истории. `journalSearch` есть в preload, но экран сейчас его не вызывает: полный поиск требует отдельной разработки.

[П] Нажатие строки открывает диалог 560×480: время, действие, доступные очищенные аргументы, риск, статус, итог и доказательство; «Закрыть». Только данные загруженной записи; отсутствие — «Нет данных», не выдумывать полные логи или стек ошибки. Текущий `recordToEntry` отбрасывает `decision`: показ фактического решения требует сохранить поле в представлении, если оно есть в ответе; иначе «Нет данных». Маскирование остаётся на стороне журнала. История чатов — отдельная панель существующего чата.
