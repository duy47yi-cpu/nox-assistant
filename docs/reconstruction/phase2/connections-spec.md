# Подключения: каталог и управление

[В] V2 00:15 показывает рекламную композицию MCP, а не читаемый каталог. Координаты и ограничения — `video-analysis.md`. Экран ниже [П], каркас — `navigation-map.md`.

При 1200×720: заголовок x80,y72,w1092,h40 и «Добавить сервис» справа. Поиск x80,y128,w360,h40; фильтры «Все», «Подключённые», «Выключенные», «Ошибка» применяются локально к загруженным записям. Ниже слева x80,w720 список подключённых, справа x812,w360 «Популярные», padding16. Карточка минимум 100 высотой: имя, безопасное отображение адреса/команды, состояние, доступные возможности и действия. Справа семь реально имеющихся записей `POPULAR` из `connections.js`, описание и «Добавить»; категории [П] «Все», «Файлы и память», «Разработка и браузер», «Прочее» — локальные группы этих записей, не внешний каталог. Поиск по безопасным именам и описаниям, не по ключам. При 864×520 колонки одна под другой, фильтры на отдельной прокручиваемой строке.

Состояния `statusOf`: connected — «Подключён» и список действий; connecting — «Подключается», повторное действие временно недоступно; disabled — «Выключен»; idle — «Не подключён»; legacy — «Подключится при запуске»; error — причина и «Повторить» через `mcpToggle(name,false)`; drift — перечень добавленных, удалённых, изменённых действий и «Подтвердить изменения» через `mcpApprove(name)`. При drift действия недоступны до подтверждения. Сохранённый, но не подключившийся сервис не считать подключённым. Пустой список, пустой поиск, сбой чтения различаются: текущий `load` в catch рисует пустой список, для различения ошибки нужен небольшой UI-адаптер.

[П] Добавление: диалог 560×480, название до 40 символов, адрес или команда до 400, аргументы через пробел до 400, пояснение о запуске, «Отмена / Добавить». Популярный вариант показывает команду и аргументы до подтверждения: некоторые запускают загрузку пакетов, установку не выполнять без согласия владельца. Не подставлять секреты. Вызов `mcpAdd(name,target,args)`; во время ожидания повторный клик выключен. Показывать фактическую ошибку и отдельно — сохранённый, но не подключившийся сервис.

[П] Нажатие карточки открывает подробности справа, на узком экране — диалог: имя, безопасный адрес/команда, статус, возможности, объяснение доступов, переключатель включения, «Удалить», «Закрыть». Данные — из `mcpState`, отдельного API настроек не выдумывать. Редактирование команды, OAuth, настройки прав отдельного действия и отзыв прав этим API не подтверждены: не рисовать как работающие. Удаление `mcpRemove`; [П] спросить имя и подтверждение перед удалением. `mcpApprove` подтверждает изменение набора действий, а `approval:respond` — решение по конкретному действию: не смешивать. Существующий опрос состояния каждые 3 с при видимом разделе сохранить. Действия сервиса проходят действующую политику.
