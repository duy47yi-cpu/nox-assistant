# Функция → код → компонент → адаптация → риск

Пути относительно `apps/jarvis-desktop/`. IPC и данные сохраняются; «новый контракт» — отдельная будущая реализация.

| Существующая функция → файл / обработчик | Компонент → адаптация | Риск регрессии |
|---|---|---|
| Список, активность, запуск → `renderer/app.js renderCmdList/runCommand`, `main.js commands:list/run`, `src/commands/runner.js` | Строка с раскрытием и кнопкой; тот же id, политика и verify | Потеря пространства, неверный успех, запуск выключенной команды |
| Создание/правка → `saveDraft`, `commands:save`, `src/commands/store.js` | Редактор с теми же полями и схемами | `store.js` сохраняет существующие `collections` и `optionalPhrases` при отсутствии их в payload; проверить старые и неизвестные шаги |
| Проверка шагов → `showPreview`, `cmd-steps.js` | План без запуска | Случайное выполнение при предпросмотре |
| Запись → `captureRecordedTool`, `commands:record-start/stop/cancel/state`, `CommandRecorder` | Панель событий инструментов и черновик | Обещание записи всех физических действий, потеря предупреждения |
| Импорт/экспорт → `commands:import-pick/import-apply/export`, `store.js` | Диалог diff и подтверждение token | Потеря конфликтов, запись без подтверждения |
| Паки → `packs:install`, `commands/packs.js` | Карточки и состав, установка по нажатию | Неявная установка и дубли |
| Библиотека → `library:list/run`, `renderLibrary`, `src/library/` | Категории, аргументы и результаты | Путаница с типами шагов, обход валидации |
| Построитель → `src/tools/commands.js command_build`, `commands/builder.js` | Чатовый сценарий; диалог требует нового контракта | Повторная генерация другого плана, фиктивная кнопка |
| Сервисы → `connections.js`, `mcp:state/add/toggle/remove/approve` | Карточки, локальный поиск, добавление/детали | Скрыть drift и ошибки; установка пакета без согласия |
| Настройки → `settings:get/set`, `settings-nav.js`, `app.js`, `look.js`, `accent.js`, `extensions.js` | Поиск и группы вокруг имеющихся полей | Сброс предпочтений, раскрытие ключей, потеря условных разделов |
| Классический шар → `orb-tune.js`, `orb.js`, `look.js` | Не менять существующие настройки | Случайная миграция на новый шар |
| Сфера Nox → `orb-nox.js`, `nox-screen.js`, `noxOrb` | Будущий блок, новый контракт параметров | Изменение чата, сброс варианта, ручки без эффекта |
| Журнал → `journal:recent/search`, `src/journal/journal.js`, `renderJournal` | Таблица и подробности из полученных полей | Ошибка за пустой список, чужое пространство, неверное подтверждение |
| Агент → `agent:event`, `agent:stop`, `approval:respond`, `src/agent/effects.js` | Ход, решение, итог | Ложные проценты, поздний успех после стопа, ложные доказательства |
| Память/напоминания/голос → `src/memory`, `src/schedule`, `src/voice`, `renderer/app.js` | Перенести существующие контролы | Потеря подтверждений, предпочтений и границ пространства |

Новые возможности: категории каталога и фильтры локальны; подробности журнала используют загруженные данные; поиск настроек — UI. Настраиваемые параметры Nox-сферы и генерация команды из редактора требуют новых контрактов. Рекламный каталог множества интеграций, полный план каждого хода и произвольная запись физического ввода не подтверждены существующей реализацией.
