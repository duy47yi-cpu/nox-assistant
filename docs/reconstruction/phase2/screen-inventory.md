# Инвентарь и переходы

Все компоновки [П]. Свидетельства [В]/оценки [О] — `video-analysis.md`; общий каркас и размеры — `navigation-map.md`.

| Представление | Состав и переходы | Состояния / спецификация |
|---|---|---|
| Чат | Существующий экран и история бесед; ход, стоп, разрешение | Без реконструкции; `agent-workflow-spec.md` |
| Команды: мои | Поиск, шаги, запуск, включение, создание, запись, импорт/экспорт, паки | Пусто, нет совпадений, ошибка, выключена; `commands-spec.md` |
| Команды: библиотека | Категории, поиск, аргументы и запуск готовой команды | Загрузка, ошибки полей и исполнения, результаты; `commands-spec.md` |
| Редактор | Новая/сохранённая, поля, шаги, выбор действия, проверка, запуск, сохранение, удаление | Черновик, ошибка, подтверждение ухода, предупреждения записи; `commands-spec.md` |
| Выбор / запись / импорт | Выбор → параметры; запись → черновик; импорт → diff → решение | Отмена, ошибка, ограничение, конфликт; `commands-spec.md` |
| Подключения | Популярные, ручное добавление, карточки и детали | Нет связи, подключение, ошибка, drift; `connections-spec.md` |
| Настройки | Категории и поиск, существующие секции; сфера Nox отдельно как будущее | Условные блоки, сохранение и ошибка; `settings-spec.md` |
| Журнал | Поиск, фильтры, таблица/карточки, подробности | Подтверждено/не проверено/провалено/ошибка/отклонено; `agent-workflow-spec.md` |
| Ход и разрешения | Текущий шаг, стоп, диалог, итог | Ожидание/проверка/успех/ошибка/отказ/остановка; `agent-workflow-spec.md` |
| Столы, аккаунт, пространства | Существующие входы и данные | Без редизайна в этой фазе; не прятать и не удалять |

Доступность, обычные и узкие размеры, анимации и пустые/ошибочные состояния определены в общей спецификации и документах экранов.
