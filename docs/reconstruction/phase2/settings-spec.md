## Сфера Nox: будущий блок «Вид → Сфера Nox»

[П] Основная карточка x344,w560; превью x916,w256,h240. При 864 превью перед настройками на всю ширину, h180. Сегмент «Wire / Nox Points»; строки: цвет (тема/свой), размер, яркость ядра, свечение, скорость; числовое значение и подсказка; в превью список состояний и «Вернуть текущее состояние». «Сбросить настройки сферы» с подтверждением сбрасывает только выбранный вариант. [П] Будущие диапазоны: размер 70–120% шаг 5, яркость ядра 0–160% шаг 5, свечение 0–160% шаг 5, скорость 0–200% шаг 5; 100% — нынешний вид. Для Wire яркость ядра выключена с пояснением. Свой цвет применяется к базовой палитре, смысловые состояния сохраняют различимость; точное смешивание нужно утвердить. Ползунки меняют только локальное превью, «Применить» сохраняет, «Отмена» восстанавливает снимок. Эти ручки для Nox-сферы ещё не подключены: не показывать как работающие до реализации.

Имеющееся: `nox-screen.js` `setVariant` уже умеет `wire`/`nox` и `localStorage.noxOrb`, штатного переключателя нет. `orb-nox.js` имеет idle, attentive, listening, thinking, speaking, waiting_approval, error, success; planning/searching/verifying → thinking, warning → waiting_approval, cancelled → idle. Рендер имеет внутренние параметры и палитры, но не публичные пользовательские ручки цветов, яркости, скорости и свечения. `look.js` хранит общий размер в `jarvis.look`; не предполагать его автоматического влияния на Nox-сферу. `orb-tune.js` хранит настройки классических core/iris/sphere в `jarvis.orbTune`, не переносить на `orb-nox.js` молча. [П] Будущая запись — собственный версионированный ключ; прежний `noxOrb` читать без миграции и менять только после применения. При reduced motion превью статично; выбор состояния не меняет реальное состояние агента. Живую сферу чата при открытии настроек не пересоздавать.
