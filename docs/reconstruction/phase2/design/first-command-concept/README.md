# Первый сценарий Nox — дизайн-концепт

Это ранний макет. Текущий экран реализован в приложении по ролику Jarvis Pro; [описание переноса](../../../jarvis-pro-video-2026-11-11.md).

## Направление

- **Продукт:** Nox помогает пользователю Windows отдавать Джарвису задачи и видеть, что произошло.
- **Характер:** точный, спокойный, ответственный.
- **Мир:** компактный пульт рабочего компьютера, с матовым графитом и тонкими инструментальными метками.
- **Моменты:** настоящая сфера Nox как единственный насыщенный визуальный объект; строка проверки результата как короткое подтверждение работы.
- **Подпись:** девятилепестковый затвор сферы меняет состояние вместе с ходом команды.

## Основания

**Наблюдалось:** пустой экран Nox уже собран из рейки, диалога, поля ввода и сферы. В пустом чате сейчас остаётся только заголовок «С чего начнём?». В разборе Luxify виден короткий путь от выбора команды к запуску; в коротких видео успешная проверка результата показана реже.

**Есть в Nox:** состояния выполнения, ожидания подтверждения и проверки результата уже описаны в `renderer/nox-screen.js`. Инструмент `app_open` сверяет открывшееся окно с запущенным процессом; проверка может подтвердить, что у процесса есть видимое окно.

**Решение для макета:** подсказать первое поручение прямо в пустом чате, сделать голосовую кнопку читаемой и показать последовательность «принято → выполнено → проверено». Пример «Открой Блокнот» использует существующий инструмент и его проверку. Кнопки над окном переключают состояния только для просмотра макета; они не запускают программу.

В рабочем интерфейсе подпись голосовой кнопки должна отражать доступность микрофона и выбранный режим. Макет не утверждает, что микрофон уже настроен.

**Неизвестно:** какая доля новых пользователей предпочитает голосовой ввод тексту; это надо проверять на живых пользователях. Наблюдения по локальным роликам в сводке выборочные, не полное покадровое изучение всех файлов.

## Признаки, проверенные против anti-slop

- Оставлена одна рабочая палитра Nox; циан отмечает активный раздел и отправку.
- Сфера остаётся фирменным визуальным элементом, новые иллюстрации и фоновые свечения не добавлены.
- Подсказки не оформлены в одинаковые большие карточки; они заполняют поле ввода.
- Текст говорит о конкретной задаче и проверке. Рекламные цифры и обещания не используются.
- Есть отдельные состояния ожидания разрешения, выполнения, проверки и результата.

## Как посмотреть

Откройте `index.html` в браузере. Верхние кнопки показывают состояния сценария; список справа меняет размер окна между 1200×720 и 864×520. Ввод примера заполняет поле. Отправка меняет только экран предпросмотра и ничего не выполняет.
