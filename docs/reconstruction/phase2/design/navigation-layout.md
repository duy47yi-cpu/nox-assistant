# Навигация и лейаут Nox

> Каркас уже реализован на первом этапе (`renderer/nox-screen.css`, `docs/reconstruction/component-spec.md`).  
> Этот документ фиксирует **единую сетку для всех разделов** и правила переключения.  
> Координаты в CSS px от левого верхнего угла окна 1200×720. Маркеры [В]/[О]/[П].

---

## 1. Общий каркас окна [П]

```
Окно Electron 1200×720 (min 960×640), frame:false, transparent:true, radius 12px
┌─────────────────────────────────────────────────────────────┐
│ .app  pad 8px  gap 0  bg #0F0F10  border #2A2A2E  radius 12 │ [В+П]
│ ┌──────┬──────────────────────────────────────────────────┐ │
│ │ Rail │ .main (flex 1, min 0)                           │ │
│ │ 52px │  ┌────────────────────────────────────────────┐  │ │
│ │      │  │ .nox-grid или .nox-workspace             │  │ │
│ │      │  └────────────────────────────────────────────┘  │ │
│ │      │  gap 8px между панелями внутри                   │ │
│ └──────┴──────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

- `.app` — `display:flex; padding:8px; gap:0; height:100vh; background:var(--nox-bg); border:1px solid var(--nox-border); border-radius:12px; overflow:clip` [В].
- В референсе рейка и история читаются как **одна панель** с общим фоном: зазор только справа от группы [В]. Реализовано как `gap:0` между rail и первой панелью + внутренние gap 8px [П].
- `.topbar` классического `presence.css` скрыт на `body[data-view="nox"]` [П].
- Window controls — кастомные в правом верхнем углу панели сферы/чата: `─ ⛶ ×` 18px, hover `surface-hover`, close hover `err 12%` [П].

### 1.1 Сетка по брейкпоинтам [П]

| Окно | Рейка `rail-w` | История/Нав `history-w` | Сфера `sphere-w` | Chat | Gap |
|------|---------------|------------------------|-----------------|------|-----|

| 864×520 min | 46px | overlay drawer 280px (см §5) | скрыта → вкладка | 1fr | 8px |

Внутренняя полезная область эталона: `x 60, y 0, w 1132, h 704` (после rail+pad) [О].  
Внутри `nox-grid`: `x 80, y 72, w 1092, h 632` для контента (заголовок 56px + контент) [П по navigation-map].

## 2. Рейка (Rail) — единственная навигация [В]

```
Width 52px (46px ≤1000px)  pad 8px 6px  bg --surface  border 1px solid --border  border-right 0  radius 16px 0 0 16px
┌──────────┐
│  ○ LOGO  │ 36×36 r 10px  border 1px  ○ 18px [В]
│──────────│ gap 4px
│ ⌂ Chat   │ 36×36 r 10px  outline 1.5px 18px  [В]
│ ⌁ Cmds   │  ─″─
│ ◷ Hist   │  ─″─
│ ◈ Conn   │  ─″─   (MCP)
│ ⚙ Sett  │  ─″─
│──────────│ flex 1 spacer
│ ◉ Acct  │ 32×32 r 50% border
└──────────┘
```

- Пункты: `Chat (nox)` / `Команды (commands)` / `Журнал (journal)` / `Подключения (mcp)` / `Настройки (settings)` — порядок фиксирован [П].
- Активный: `bg accent-soft (14%)`, `icon accent`, `left bar 4×22px pill left -9px bg accent` [П].
- Hover: `bg surface-hover (mix 6%)`, `text-1` [П].
- Label под иконкой **нет**; tooltip при hover `12px/500` [В].
- Счётчик на иконке: `min 15×15 r pill bg accent text ink 10px/600` [О].
- Горячие клавиши: `Ctrl+1…5` соответствуют порядку рейки + `data-nav` атрибут [П].
- Внизу: акаунт 32px аватар + dot, `#railToggle` скрыт на Nox-виде [П].
- `app-region: drag` на пустых зонах рейки для перетаскивания окна [П].

Состояния рейки [П]:
- Default: `text-3 #6B6B70`
- Hover: `text-1 + surface-hover`
- Active: `accent-soft + accent + left bar`
- Focus-visible: `outline 2px accent offset 2px`
- Disabled: не используется (всегда доступны)

## 3. Типовой лейаут раздела [П]

Каждый раздел (кроме чата) использует **двухколоночный `nox-workspace`**:

```
.nox-workspace  display:flex  gap 8px  height 100%
┌────────────────────────────┐ ┌──────────────────────────────────┐
│ .nox-history / .nox-nav    │ │ .nox-main                        │
│ 244–252px  bg surface      │ │ 1fr  bg surface  border 16px    │
│ border 1px  radius 0 16 16 0│ │ border 1px radius 16px pad 16–20│
│ pad 16/12                  │ │ overflow-y auto                  │
│ (или 252px nav настроек)   │ │                                  │
└────────────────────────────┘ └──────────────────────────────────┘
    ↑ история чатов / фильтры /         ↑ список команд / таблица журнала /
      навигация настроек                  карточки подключений / настройки
```

Заголовок раздела внутри `.nox-main`:

```
.nox-main-head  h 56px  flex row space-between  pad 20px  border-bottom 1px subtle
  Title: 24px/600/text-1
  Actions: gap 8px  btn 36/40px  (search 260px + primary)
```

Для узких панелей (команды 800px + паки 280px) — см. §4.

### 3.1 Заголовок + поиск + действия

- Высота 56px фиксирована для всех разделов [П].
- Search: `w 260–360px h 40px r 8px bg surface-3 border 1px text-2 → focus accent ring` [П].
- Actions справа: `gap 8px`, высота 36px вторичные / 40px первичная [П].
- Tabs (команды): `y 128 h 40` «Мои · N» + «Библиотека · N» [П по commands-spec].

## 5. Адаптивность и состояния панели

### 5.1 Rail+History как единая панель [В]

- Рейка `bg surface + border-right 0 + radius 16 0 0 16`, история `border-left 0 + radius 0 16 16 0` → визуально одна панель [П по PHASE-1.1].
- В пустом чате (`is-empty`) история скрыта, центральная панель чата получает `border-left 0 + radius 0 16 16 0` и продолжает левую группу [П].

### 5.2 Узкое окно (≤864px) [П]

- Rail 46px (кнопки 32×32).
- История / nav настроек — не скрываются навсегда: открываются как **overlay drawer** 280px поверх контента, `bg surface + border + shadow-popover`, закрытие по Esc/клику вне.
- Сфера чата — отдельный таб: кнопка «Сцена» в rail (или переключатель в чате), не overlay.
- Фильтры — горизонтальный скролл `overflow-x auto; scrollbar none`.
- Таблицы → карточки.
- Composer чата — `inset 12px` вместо 20px; высота остаётся 76px.

### 5.3 Защита от переполнения [П]

- Все `.nox-main` — `min-width:0; min-height:0; overflow-y:auto` — скролл внутри, не каркаса.
- Длинные строки — `overflow-wrap: anywhere` + `min-width:0` на flex-children.
- Кнопки не перекрываются: `flex-wrap: wrap` при нехватке ширины.
- Минимальное окно определяется `createWindow 960×640`; меньшее не тестируется.

## 7. Переходы между разделами [П]

- Переключение рейки — не анимация страницы, а `fade 120ms ease-default` контента `.views > *` [П].
- Active индикатор рейки — `left bar` slide 200ms `ease-out`.
- Search/фильтр — немедленная фильтрация локальных данных; debounce 150ms для ввода [П].
- История чата → Чат: клик по item → `composer` не дёргается, `feed` smooth scroll [П].
- Dialog → underlying: затемнение `rgba(0,0,0,0.48) 120ms`, диалог `rise 200ms cubic(0.16,1,0.3,1)` [П].

### 7.1 Схема навигации (текстовая)

```
Rail click / Ctrl+1..5
  ├─ [nox]       Chat — чат + история чатов + сфера (эталон, уже готов)
  ├─ [commands]  Команды — список/библиотека ↔ редактор ↔ диалог выбора ↔ запись/импорт
  ├─ [journal]   Журнал — таблица ↔ диалог деталей (agent-workflow)
  ├─ [mcp]       Подключения — список + популярные ↔ диалог добавления ↔ детали карточки
  └─ [settings]  Настройки — нав + поиск ↔ карточки (общие + сфера Nox)
       └─ future: Sphere Nox controls (не активны до backend)
```

Каждый раздел сохраняет `scrollTop` при уходе и возврате [П].

## 8. Диалоги поверх лейаута [П]

- Overlay `rgba(0,0,0,0.48)` перекрывает `.main` (не всё окно).
- Диалог центр `min(640px, win-32px) × max(win-32px)`; header h60 + body scroll + footer h64 fixed.
- Escape / крестик = Отмена; фокус возвращается к вызвавшей кнопке.
- При reduced-motion — без slide, только fade 0ms.

## 9. Чек-лист приёмки лейаута

- [ ] Rail 52→46px, history 244px, gap 8px, radius панели 16px.
- [ ] 1200×720 и 864×520 без горизонтального скролла; длинный текст не ломает сетку.
- [ ] История и чат читаются как разные сущности (история ≠ журнал).
- [ ] Фильтры на узком — горизонтальный скролл, не перенос в 3 строки.
- [ ] Переключение разделов — без белого flash, fade 120ms.
- [ ] Dialog не выходит за `win-32px`, footer закреплён.
