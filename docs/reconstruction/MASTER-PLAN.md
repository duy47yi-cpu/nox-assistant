# Общий план Nox: кто что делает

Дата: 12.11.2026. Пишу как владелец. Это единственный список работ для всех моих агентов. Основание: сверка с Luxify 2.2.2 (`docs/reconstruction/luxify-2.2.2-gap-analysis.md`) и то, что уже сделано в коде.

## Правила для всех

1. Сначала прочитай `AGENTS.md` в корне: карта файлов и запреты.
2. `.env` и настоящую `data/` не читать. Проверки — во временной папке через `NOX_DATA_DIR`.
3. Коммит и push — только по моей просьбе. Пакеты и программы не ставить без моего согласия.
4. Оплаты нет. Названий моделей и поставщиков пользователь не видит.
5. Новый файл в `src/` или `renderer/` — строка в `AGENTS.md`, иначе упадёт `tests/project-map.test.js`.
6. Готово = `node --test` проходит в `apps/jarvis-desktop` и `apps/nox-server`, интерфейс снят настоящим окном (`scripts/nox-shot.js`, `scripts/nox-settings-shot.js`).
7. Имена, картинки, тексты и макеты Luxify не копировать. Берём только задачи пользователя.
8. Бери одну задачу. Не трогай файлы чужой задачи. Меньше кода — лучше.

**Общие файлы, где легко столкнуться:** `main.js`, `preload.js`, `renderer/app.js`, `renderer/index.html`, `AGENTS.md`. В них одновременно пишет только один агент. Если твоя задача их задевает — правь маленьким куском и скажи мне об этом в отчёте.

**Отчёт мне:** что сделано простым русским, какие файлы изменены, снимки окна, что не проверено и почему.
