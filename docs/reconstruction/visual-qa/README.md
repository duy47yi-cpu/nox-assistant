# Пакет визуальной проверки Nox

Этот пакет собирает ключевые сравнения для исправления первого экрана. Изображения реализации были сняты 9 ноября 2026 в чистом временном профиле при DPR 1; текущая открытая сессия имеет пользовательский шрифт Sitka/Georgia, что отдельно описано в `../visual-qa-2026-11-10.md`.

## Ключевые изображения

- [`chat-wire-864-compare.png`](./chat-wire-864-compare.png) — оригинал `IMG_22660.mp4` около 12 с и экран Nox wire при 864×520 рядом. Основное сравнение геометрии и фактуры.
- [`chat-nox-1200-compare.png`](./chat-nox-1200-compare.png) — исходник против Nox Points; вариант точек — идентичность Nox, не копия оригинального wire.
- [`sphere-wire-compare.png`](./sphere-wire-compare.png) — увеличенное сравнение исходной wire-сферы с реализацией.
- [`current-wire-864.png`](./current-wire-864.png) — реализация при размере, близком к исходному ролику.
- [`current-nox-1200.png`](./current-nox-1200.png) — полный экран с точечной сферой.
- [`geometry-864.json`](./geometry-864.json) и [`geometry-1200.json`](./geometry-1200.json) — координаты DOM, DPR 1.
- [`reference-sphere-2x.png`](./reference-sphere-2x.png) — увеличенный исходный шар.

## Как читать сравнения

Слева показан оригинал, справа — реализация. Видеореференс сжат и смонтирован; мелкие шумы, световые полосы и абсолютные размеры шрифта не являются точными CSS-измерениями. Для геометрии использовать пары в одинаковом размере, для движения — исходные кадры временного ряда в `../detail/`.
