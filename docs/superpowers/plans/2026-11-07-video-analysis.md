## Общая карта переноса

1. Агент: запрос → план → шаги → разрешение → действие → независимая проверка → честный итог → история → сохранение безопасной команды.
2. Команды: дерево, папки, коллекции, поиск, фразы, клавиши, ручной редактор, запись, генерация из текста, импорт/экспорт, пробный просмотр, включение/выключение.
3. Чат: история, вложения, потоковый ответ, состояния выполнения, голос, отмена и повтор после ошибки.
4. Память и дела: просматриваемые/редактируемые заметки, задачи, календарь, напоминания, память по рабочему месту.
5. Подключения: каталог официальных интеграций, минимальные разрешения, подтверждение действий, отключение и диагностика.
6. Персонализация: живой шар с разными состояниями, цвета, фон, шрифт, прозрачность/размытие, отключение движения.
7. Столы: вкладки, шаблоны, виджеты, редактируемая сетка и восстановление после перезапуска.
8. Расширения: скриншоты/OCR/запись; конвертер; буфер; вставки; поиск документов; помощник стримера; уборка; перерывы. Отдельно исследовать умный дом, субтитры, конспекты, чтение, блокировку, второй ПК, озвучку уведомлений и питомца.
