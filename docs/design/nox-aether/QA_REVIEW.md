## Зафиксированные замечания для Gate 2

1. **`[M]` Контраст текста при ручном центрировании сферы в Концепции C** (`prototypes/c/index.html`) — при смене положения сферы вручную на центр и максимальной ширине чата без автосдвига адаптивный `.scrim` в Gate 2 должен подстраиваться под центр свечения для гарантированного контраста `>= 7:1` на всех 22 темах.
2. **`[L]` Воздушность точек `Jarvis Точечная` в мини-карточке каталога 56–72 px** (`prototypes/shared/proto.js`, `*_orblib_*.png`) — из-за особенностей освещения `JarvisOrb` на малом холсте точки заметно реже/бледнее, чем плотная 1400-точечная матрица `NoxOrb`; в `JarvisOrbAdapter` для миниатюр каталога (Gate 2) стоит задать более яркий превью-пресет без изменения основного холста. *(Примечание координатора: сейчас передаётся `density: 1.75` и `glow: 1.15` только превью-карточке.)*
3. **`[L]` Вертикальный скролл каталога сфер при высоте 520 px** (`*_orblib_864x520.png`) — две колонки карточек уже влезают по ширине, но нижняя секция («Контур и свет», пресеты и «Своя сфера») требует прокрутки по высоте; при желании в Gate 2 можно сделать компактную сетку или табы семейств.
4. **`[NOT RUN]` Не проверялось в Gate 1 (запланировано на Gate 2):** живое окно Electron (`npm start`), реальный цикл агента `src/agent/loop.js`, системная диктовка/микрофон, замер FPS/CPU в Electron.
