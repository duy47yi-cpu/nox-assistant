## Что построить: 3 действительно разных концепции
**A / Minimal Presence** — камерная композиция: сфера крупная, воздух; в диалоге акцент переходит на текст; навигация — сворачиваемая тонкая рейка.
**B / Fluid Workspace** — две зоны с переключаемой композицией «разговор ↔ присутствие», действия — компактные слои/раскрывашки; панели меняют баланс; НИКАКИХ постоянных метрик.
**C / Spatial Dialogue** — сфера и разговор — одна сцена без жёсткой границы; при длинном тексте сфера уменьшается/смещается, но узнаваема; приоритет — контраст и читаемость на 864×520.

Владелец ОТВЕРГ прежние концепции: отчёты, таблицы, KPI, много статусных карточек, «офисная панель», постоянный Nox Live на пол-экрана. Не копируй Jarvis Pro (цвета, логотип, форму) — бери только принцип баланса/воздуха. Современно, тёмно, очень чисто, самобытно, красивая типографика (в проекте есть Inter и IBM Plex Serif, `renderer/fonts/` — можно подключить через @font-face по относительному пути), спокойные анимации, акцент меняется. Это личный ассистент, не CRM и не копия ChatGPT.

## Одинаковые 6 сценариев в КАЖДОЙ концепции (одни и те же тексты!)
1. Пустой чат (одна ясная фраза «С чего начнём?» + сфера, без виджетов).
2. Обычный диалог (короткий вопрос — ответ; 2–3 реплики).
3. Длинный ответ: Markdown (заголовки, списки, цитата, таблица с горизонтальным скроллом, блок кода с кнопкой «Копировать», ссылки, «Источники · 3»).
4. Выполнение 8+ инструментов: компактная запись «ход задачи», группа сворачивается в одну строку и раскрывается; статусы **проверено / создано, не подтверждено / не удалось** различаются; один шаг с ошибкой и безопасным следующим действием.
5. Запрос подтверждения: ЧТО (действие), ГДЕ (папка/сайт/окно), РИСК; кнопки «Разрешить»/«Отклонить»; фокус и Esc/Enter; видно, что подтверждение относится к конкретному запросу.
6. Голос: слушаю/говорю — сфера реагирует на (демо-)уровень сигнала; подпись состояния простыми словами (готов, слушаю, работает, ждёт вас, отвечаю, ошибка).
Плюс **«Мастерская Nox»**: разделы Сферы / Композиция / Чат / Цвета и фон / Эффекты / Мои оформления. В «Сферах» — карточки реальных рендеров кандидатов (см. ниже) с отметкой «Оригинальная», «Выбрать», «Установлено», честным списком поддерживаемых параметров (поддерживает не всё — недоступное серым). Ползунки/переключатели в Композиции и Чате должны **действительно** менять прототип (ширина диалога, положение сферы справа/слева/компактная/скрыта, плотность, стиль сообщений Minimal/Cards/Hybrid, размер шрифта, акцент, motion off/reduced/balanced/expressive).

## Критерии приёмки (самопроверь до сдачи)
- Нет внешних зависимостей по сети; нет ошибок в консоли; при 864×520 нет горизонтального скролла страницы, композер не обрезан; контраст текста ≥ 4.5:1; видимый фокус; `prefers-reduced-motion` отключает анимации.
- Три концепции различаются композицией, а не только цветом. Узнаётся Nox, а не корпоративный трекер.
- Никаких «84%» и фальшивых прогрессов; в демо-статусах «проверено» только там, где в сценарии это объяснено подписью демо.
