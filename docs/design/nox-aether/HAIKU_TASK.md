# TICKET Q1 — Haiku 5.5 — независимая проверка дизайна (read-only)

Ты НЕ дизайнер и НЕ правишь файлы Fable. Пишешь только в `docs/design/nox-aether/HAIKU_QA.md` и `screenshots/qa/`.

## Вход
- Бриф: `package/01_VISUAL_DESIGN_SPEC.md` (§2 требования, §3 чат, §4 направления, §7 что должно быть на макетах), `package/03_ORB_INVENTORY_AND_CUSTOMIZATION.md`.
- Референсы: `package/assets/*.png`.
- Сдача Fable: `prototypes/{a,b,c}/index.html`, `prototypes/INDEX.md`, `screenshots/concept*_*.png`, `FABLE_PROGRESS.md`.

## Что проверить (по каждой концепции A, B, C)
1. Все ли 6 сценариев + Мастерская есть как снимки 1200×720 и нужные на 864×520; соответствуют ли имена файлов; соответствуют ли снимки прототипу (открой прототип, сверь 2 сценария).
2. Читаемость: размер основного текста ≥ 14px, строка ответа разумной длины, контраст; не обрезан ли композер/кнопки при 864×520; нет ли горизонтального скролла страницы; видимый фокус; работа Tab/Esc/Enter в подтверждении.
3. Запреты: постоянные KPI/метрики/таблицы-дашборды; фальшивые проценты; «проверено» без пояснения демо; названия моделей/провайдеров; пересказ скрытых рассуждений; копирование Jarvis Pro.
4. Отличие концепций: чем реально различаются композиции (да/нет и почему).
5. Сферы: рендерится ли реальный модуль, не нарисованная картинка; консоль без ошибок; одновременно не крутятся несколько тяжёлых canvas; `prefers-reduced-motion`.
6. Мастерская: есть ли ≥ 2 кандидата сфер с пометкой «Оригинальная»/«ожидает подтверждения», честные недоступные параметры, реально ли работают хотя бы ширина диалога, положение сферы, стиль сообщений.

## Формат ответа (кратко, конкретно)
Для каждой концепции: PASS/FAIL по пунктам 1–6, список дефектов `[severity H/M/L] файл/сценарий/координата — что не так — предложенное исправление`. Не подтверждай то, чего не воспроизвёл: пиши «не проверял». Без пересказа брифа. Не больше 1 страницы на концепцию.
