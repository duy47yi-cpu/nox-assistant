# NOX AETHER — Прототипы и снимки (Gate 1)

Автономные визуальные макеты трёх концепций единого окна Nox.
Все данные диалога и инструментов — демонстрационные; рабочий `apps/jarvis-desktop/renderer/` не изменён.

## Быстрый запуск в браузере или Electron-просмотре

- **Концепция A — Minimal Presence:** `docs/design/nox-aether/prototypes/a/index.html`
- **Концепция B — Fluid Workspace:** `docs/design/nox-aether/prototypes/b/index.html`
- **Концепция C — Spatial Dialogue:** `docs/design/nox-aether/prototypes/c/index.html`

> Если браузер открыт напрямую через `file:///`, часть шрифтов или canvas может зависеть от политик CORS; надёжнее открывать с локального статического сервера от корня `D:\nox-release`.

## Переключатель всех 7 состояний (+ голос) через URL-хэш

| Вид в ТЗ | Назначение | Хэш |
|---|---|---|
| 1. Пустой чат | Сфера в центре, приветствие «С чего начнём?» и поле ввода | `#scenario=1` |
| 2. Обычный разговор | Короткий диалог + свёрнутый «Ход задачи» | `#scenario=2` |
| 3. Длинный ответ | Статья, таблица, блок кода, цитата, список источников | `#scenario=3` |
| 4. Выполнение инструментов | Шаги с честными статусами (`проверено` / `не подтверждено` / `не удалось` / `идёт`) | `#scenario=4` |
| 5. Ожидание подтверждения | Сфера в режиме внимания + диалог решения с рисками и клавишами | `#scenario=5` |
| 6. Настройка внешнего вида | Мастерская: композиция, положение сферы, ширина чата, стиль сообщений, цвета | `#scenario=2&workshop=layout` |
| 7. Выбор сферы из библиотеки | Обе системы (`NoxOrb` и `JarvisOrb`), отдельные настройки на сферу, пресеты и «Своя сфера» | `#scenario=2&workshop=orbs` |
| Доп. Голос | Живой отклик сферы на демо-уровень голоса и переключатели состояний | `#scenario=6` |

Можно передавать параметры прямо в адресе через строгую схему `set=...`, например:
- `#scenario=2&set=orbPos:left,msg:cards`
- `#scenario=3&set=autoshift:true,chatW:740`
