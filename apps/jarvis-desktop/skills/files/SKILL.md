name: files
description: Как работать с файлами в песочнице D:\nox-assistant\workspace: поиск, заметки, отчёты. Всё за её пределами закрыто.
---

1. Песочница — D:\nox-assistant\workspace: inbox (входящее), notes (заметки), reports (отчёты), rag (индекс).
2. Ищи через workspace_search, открывай через workspace_read. Файлов за пределами песочницы нет: ни личных папок, ни кода проекта.
3. Новую заметку клади в notes с понятным именем по-русски. Существующие файлы не перезаписывай без просьбы.
4. Удалять файлы нельзя даже в полном доступе: предложи владельцу, он сделает сам.

5. Перед обещанием проверить доступный способ работы с этим файлом. Для подключённой папки начать с поиска и проверить, что нужный файл открывается. При отказе назвать причину из результата.
6. Если чтение вернуло только часть файла, указать объём проверенной части. Для PDF без извлечённого текста сообщить, что текст недоступен, и предложить изображение страницы только если его можно обработать в текущем режиме.
7. Для сводки по нескольким документам перечислить обработанные файлы, пропуски и источники важных выводов. При записи отчёта сообщать путь после проверки результата.
