# Telegram-бот DeepSeek Harness

Бот в Telegram, который работает на этом компьютере через **DeepSeek Harness** (`dsh headless`).
Пишешь боту — он выполняет задачу на ПК и отвечает в чат. Пока работает — показывает экран и не теряет сообщения.

## Что умеет

- **Задачи на ПК.** Любой текст уходит агенту harness с полным доступом: файлы, терминал, программы, интернет.
- **Несколько сессий.** У каждой сессии своя история harness и своя рабочая папка. Работают параллельно и не перебивают друг друга.
- **Очередь вместо «занят».** Пока сессия работает, новые сообщения ждут и выполняются по порядку — ничего не теряется.
- **Перебивание.** Начни сообщение словом `перебей`, `поменяй`, `исправь`, `переделай`, `заново`, `стоп` — текущий ход снимается и сразу выполняется новое указание.
- **Показ экрана.** Живая картинка в одном сообщении (обновляется на месте, без спама) — `/screen on`; один снимок — `/shot`.
- **Настоящая трансляция в Telegram-эфир.** Вы начинаете трансляцию в видеочате Telegram Desktop, присылаете боту RTMP-адрес — бот гонит туда экран через ffmpeg: `/stream rtmp://…`.
- **Управление приложениями.** Может открыть Claude Code, ChatGPT/Codex, Roblox Studio, любой терминал — через команды Windows.
- **Переживает перезапуск.** Сессии harness хранятся на диске; бот продолжает разговор с того же места.

## Команды

| Команда | Что делает |
|---|---|
| `/help` | краткая справка |
| `/new имя [папка]` | новая независимая сессия (по умолчанию папка `D:\nox-release`) |
| `/use имя` | переключить активную сессию |
| `/sessions` | список сессий и что сейчас работает |
| `/stop` | прервать текущий ход активной сессии |
| `/kill имя` | прервать ход в указанной сессии |
| `/cwd путь` | сменить рабочую папку активной сессии |
| `/screen on \| off` | живая картинка экрана в одном сообщении (обновляется на месте) |
| `/shot` | один снимок экрана |
| `/stream rtmp://… \| off` | настоящая трансляция экрана в Telegram-эфир (RTMP-адрес из видеочата) |

## Как устроено

```
Telegram ── getUpdates ──> index.js ──> dsh headless (--json) ──> DeepSeek Harness
                                   └── ScreenStreamer (ffmpeg gdigrab) ──> sendVideo/sendPhoto
```

- `index.js` — приём сообщений, команды, очередь сессий, прерывание, показ экрана.
- `lib/telegram.js` — клиент Bot API без зависимостей (текст, фото, видео, «печатает»).
- `lib/dsh.js` — запуск `dsh headless` как дочернего процесса: поток событий JSON, `--session-id` для продолжения, снятие дерева процессов при прерывании.
- `lib/screen.js` — `ffmpeg -f gdigrab`: дешёвый кадр для сравнения, ролик 4 c при изменении, «живой» кадр раз в 20 c при тишине.
- `lib/store.js` — атомарная запись JSON.

## Настройки

`C:\Users\<пользователь>\.dsh\telegram-harness\config.json`:

| Поле | Смысл |
|---|---|
| `token` | токен бота от @BotFather |
| `ownerChatId` | привязывается сам на первом сообщении (можно вписать заранее) |
| `cwd` | папка по умолчанию для новых сессий |
| `permissionMode` | `read-only` / `workspace-write` / `danger-full-access` |
| `maxParallel` | сколько сессий могут работать одновременно |
| `autoScreen` | включать показ экрана при привязке чата |
| `screen.mode` | `video` (ролики) или `photo` (снимки при изменении) |
| `screen.segSec` | длина ролика в секундах |
| `slowNoticeMs` | через сколько секунд молчания бот пишет «ещё работаю» |

## Запуск

- Автозапуск при входе в Windows: ярлык `DSH Telegram Bot` в папке «Автозагрузка».
- Вручную: `wscript.exe D:\nox-release\apps\telegram-harness\run-bot.vbs` (без окна консоли).
- Журнал: `~/.dsh/telegram-harness/log.txt`.
- Один экземпляр: замок `bot.pid`; второй запуск сразу выходит.

Требуется: Node.js 24+, ffmpeg в `PATH`, установленный DeepSeek Harness с ключом модели.
