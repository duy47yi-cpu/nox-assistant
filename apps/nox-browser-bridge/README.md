# Независимый канал браузера

Мост пока не подключён к `main.js`/`preload.js` и общим политикам Nox. `createBridge({ origin })` принимает точный Origin установленного расширения; `listen()` слушает только `127.0.0.1` на случайном порту. `pair(ttlMs, { sessionTtlMs })` создаёт одноразовые случайные `id` и `secret` сопряжения (до 5 минут). После успешной проверки одноразовое сопряжение уничтожается, а для установленной сессии из handshake выводится отдельный сессионный секрет с собственным ограниченным сроком жизни (по умолчанию 15 минут, до 1 часа). `revoke(id)` немедленно завершает связанную сессию по ID сопряжения или ID сессии и стирает секрет из памяти. Вся информация о сопряжениях, сессиях и текстах страниц хранится только в памяти и не пишется на диск или в логи.

`client.mjs` — браузерная сторона проверки сервера (протокол `nox-bridge-2`, неэкспортируемый `CryptoKey` в памяти, кадры до 64 KiB). Поддерживаются подписанные сообщения `ping`/`pong` и `read_request`/`read_result` (направление `s2c`/`c2s`, защита содержимого, `requestId`, монотонный `seq`, ограничение одного активного запроса и таймаут, лимит текста 48 KiB по UTF-8 байтам и кадра 64 KiB). Удалённый `read_request` не может выбирать `tabId` или выдавать согласие. Клики и ввод отключены. Для проверки: `node --test` в этой папке.
