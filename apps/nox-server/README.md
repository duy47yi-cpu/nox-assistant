# Сервер Nox

Аккаунты, лимиты подписок и пересылка запросов к модели. Нужен Node 24 или новее, сторонних библиотек нет.

```bash
NOX_FAST_KEY=ключ-быстрой NOX_SMART_KEY=ключ-умной NOX_ADMIN_KEY=длинный-служебный-ключ node index.js
```

Настройки в окружении: `PORT`, `HOST`, `NOX_DB`, `NOX_MODELS_FILE` (провайдеры, модели и цены, образец в `models.js`), `NOX_PLANS_FILE`, `NOX_GLOBAL_DAILY_USD`, `NOX_TRUST_PROXY`, `NOX_SESSION_TTL_DAYS` (срок сессии в днях, по умолчанию 30), `NOX_UPSTREAM_TIMEOUT_MS` (сколько ждать модель, по умолчанию 120000). Имена переменных без значений — в `.env.example`.

Сервер слушает только локальный адрес. Наружу он выходит через прокси с HTTPS; за прокси поставьте `NOX_TRUST_PROXY=1` (прокси должен сам выставлять `X-Forwarded-For`, иначе ограничения по адресу обходятся).

## Аккаунты и сессии

Регистрация, вход, выход, `GET /v1/me`, лимиты. Пароль хранится только как scrypt-хеш с солью и версией параметров; старый хеш переписывается при успешном входе. Пропуск (`nox_…`) в базе только хешем, живёт `NOX_SESSION_TTL_DAYS`. Выход отзывает текущий пропуск, отключение аккаунта — все его пропуска.

Ограничения запросов: регистрация — 5 в сутки с адреса; вход — 10 попыток за 15 минут на адрес+почту и 60 за 15 минут на адрес; одновременных запросов модели — 3 на аккаунт; неудачных служебных попыток — 20 за 15 минут с адреса.

## База и резервные копии

SQLite в режиме WAL. Старая база доводится миграциями при запуске, данные не теряются; база новее сервера — понятная ошибка при запуске. Битая база тоже даёт ошибку с подсказкой, а не падение посреди работы.

```bash
npm run backup                  # копия рядом с базой: apps/nox-server/nox-backup-<дата>.db
node backup.js путь/копия.db    # или в выбранный файл
```

Копия — цельный снимок (`VACUUM INTO`). Существующий файл не перезаписывается. Восстановление: остановить сервер, положить копию на место `NOX_DB` (по умолчанию `apps/nox-server/nox.db`), запустить сервер.

## Пока нет (нужно для выпуска)

Размещения, домена и HTTPS; подтверждения почты и сброса пароля; оплаты (смена тарифа — только `POST /v1/admin/plan` со служебным ключом); удаления аккаунта. Без подтверждения почты пробный период обходится, поэтому это блокер выпуска вместе с размещением и оплатой — подробнее в `docs/business/plan.md` и `docs/superpowers/plans/2026-11-07-matrix-server.md`.

Приложение подключается настройкой `NOX_SERVER_URL`. Смена тарифа: `POST /v1/admin/plan` со служебным ключом, тело `{"email", "plan"}`. Тесты: `node --test`.
