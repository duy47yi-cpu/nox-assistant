# Чего не хватает Nox и какие доноры это закрывают

Проход 9 ноября 2026 года: код репозитория (коммит `7e6cdc5`) и открытые проекты. Лицензии сверены по файлам LICENSE на GitHub; где сверить не удалось, написано «не проверено». Код из доноров не переносился — здесь только что взять и какой пробел это закрывает.

Решения владельца остаются как есть: «Полный доступ» не сужается списком запрещённых команд, Windows Hello не добавляется без просьбы, оплату всегда делает человек.

## Чего не хватает

| # | Пробел | Что видно сейчас | Чем закрыть |
|---|---|---|---|
| 1 | Ход не продолжается после перезапуска | снимка хода с продолжением нет | журнал шагов в стиле DBOS |
| 2 | Плоский снимок страницы и окна | элементы списком, без дерева и ссылок | agent-browser, agent-desktop |
| 3 | Нет отдельного рабочего места агента | Джарвис работает прямо на экране владельца | идея Agent Workspace из Windows; только как необязательный режим, «Полный доступ» не сужает |
| 4 | Нет автообновления и подписи | `autoUpdater` и `electron-updater` в коде — 0 совпадений; настроек подписи (`codesign`, `signtool`, `certificateFile`) нет; подпись через переменные окружения — не проверено | штатные electron-builder publish и electron-updater |
| 5 | Нет CI | папки `.github` нет; корневой `npm test` запускает только тесты приложения; `project-map.test.js` падает на чистой копии, потому что `.gitignore:12` — `/workspace/` | GitHub Actions на windows-latest, Electronegativity, secretlint |
| 6 | Нет подагентов и плагинов | по `subagent` и «плагин» — 0 совпадений | идеи Claude Cowork |
| 7 | Сервер только локальный | нет хостинга, оплаты, сброса пароля | Better Auth |
| 8 | Мало живых проверок на Windows | часть функций проверена только юнит-тестами | WindowsAgentArena |

## Не брать

- **screenpipe** — коммерческая лицензия ([LICENSE](https://github.com/screenpipe/screenpipe/blob/main/LICENSE.md), [объявление](https://screenpipe.com/blog/screenpipe-license-update)).
- **LiteLLM** — Python, а нужные уровни ограничений есть только в Enterprise ([rate limit tiers](https://docs.litellm.ai/docs/proxy/rate_limit_tiers)). Взять только идею: личный бюджет и мягкое предупреждение до жёсткого лимита ([users](https://docs.litellm.ai/docs/proxy/users)).

## С чего начать

1. CI на Windows: windows-latest, `node --test` в обоих приложениях; починить `project-map.test.js`; серверные тесты — в корневой `npm test`.
2. Продолжение после перезапуска: журнал шагов в стиле DBOS.
3. Дерево со ссылками: agent-browser для страниц, agent-desktop для окон.
