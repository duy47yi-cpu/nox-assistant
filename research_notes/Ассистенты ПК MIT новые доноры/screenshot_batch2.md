## MIT-проекты и уже учтённые MIT-кандидаты

### Takeaway

Новые наиболее применимые к Nox MIT-проекты: OpenAdapt, Midscene.js, Agent Zero и Silero VAD. Для архитектурных идей полезны OpenCode, Pydantic AI, LangGraph, Pi Mono, Supermemory и Chonkie. В каталог уже входят OpenHands, OpenHands Software Agent SDK и Microsoft UFO; повторно добавлять их не нужно.

### Cited Findings

- **OpenAdapt — новый MIT-кандидат, 1,9 тыс. звёзд.** [OpenAdaptAI/OpenAdapt](https://github.com/OpenAdaptAI/OpenAdapt) описывает запись показанного владельцем workflow в локальную программу, детерминированный повтор и проверку результата; корневая лицензия MIT. Текущая структура переносит движок в packages/flow и агент в packages/agent ([описание движка](https://github.com/OpenAdaptAI/openadapt-flow), [ссылка на пакет агента](https://github.com/OpenAdaptAI/OpenAdapt/tree/main/packages/agent)). Кодовая ценность для Nox — программа вместо повторной генерации плана, результат-проверка и остановка при несовпадении; сравнить с src/commands/runner.js, src/agent/effects.js и src/control/desktop-lock.js. Старые отдельные репозитории openadapt-flow и openadapt-agent архивированы и перенесены в монорепозиторий ([flow](https://github.com/OpenAdaptAI/openadapt-flow), [agent](https://github.com/OpenAdaptAI/openadapt-agent)).
- **Midscene.js — новый MIT-кандидат, 15,5 тыс. звёзд.** [web-infra-dev/midscene](https://github.com/web-infra-dev/midscene) — MIT-проект для визуального E2E управления web, mobile и desktop UI; README описывает шаги естественным языком, выполнение через визуального агента и проверку ожидаемого результата. Репозиторий содержит JavaScript SDK, примеры и отчёты шага с входом, выходом и снимками ([README](https://github.com/web-infra-dev/midscene)). Это хорошее сравнение для браузерных/экранных действий Nox и src/agent/effects.js. Точный пакет внутри монорепозитория нужно выбрать после фиксации ревизии.
- **Agent Zero — новый MIT-кандидат, 19,8 тыс. звёзд.** [agent0ai/agent-zero](https://github.com/agent0ai/agent-zero) и его корневой [LICENSE](https://github.com/agent0ai/agent-zero/blob/main/LICENSE) указывают MIT. README направляет к prompts/, tools/ и plugins/ и описывает расширения и MCP; Windows доступен через launcher/host connector, а основной рабочий компьютер агента — Linux окружение в Docker ([README](https://github.com/agent0ai/agent-zero)). Полезен для структуры инструментов и расширений, но его полноценная среда не является прямой заменой Windows/Electron-ядра Nox.
- **Silero VAD — новый MIT-кандидат, 10,6 тыс. звёзд.** В [snakers4/silero-vad](https://github.com/snakers4/silero-vad) корневой [LICENSE](https://github.com/snakers4/silero-vad/blob/master/LICENSE) — MIT; код лежит в src/silero_vad/, есть examples/ и tests/. README рекомендует VAD для voice interfaces и заявляет MIT, но alt-текст бейджа в том же README показывает CC BY-NC 4.0, хотя ведёт на корневую MIT-лицензию ([README](https://github.com/snakers4/silero-vad/blob/master/README.md)). Для Nox это полезно для пауз, конца фразы и barge-in в src/voice/dictation.js и src/voice/modes.js; нельзя включать веса в продукт, пока не проверены лицензии каждого файла модели и исправленное/действующее пояснение проекта.
- **OpenCode — новый MIT-кандидат, около 224,7 тыс. звёзд.** [anomalyco/opencode](https://github.com/anomalyco/opencode) помечен GitHub как MIT; это открытый coding agent на TypeScript, с исходниками в пакете packages/. Подходящий источник — агентный цикл, маршрутизация инструментов и поток событий; сравнивать с src/agent/loop.js и src/tasks/. Это coding CLI, а не desktop assistant, поэтому ценность — отдельные приёмы, не архитектура продукта целиком ([репозиторий](https://github.com/anomalyco/opencode)).
- **Pydantic AI — новый MIT-кандидат, около 21 тыс. звёзд.** [pydantic/pydantic-ai](https://github.com/pydantic/pydantic-ai) — Python MIT-фреймворк с агентами, инструментами, realtime voice, image generation и embedding support ([репозиторий](https://github.com/pydantic/pydantic-ai), [официальный список репозиториев](https://github.com/orgs/pydantic/repositories)). Для Nox полезны типизированные границы инструментов и структурированные ответы; ядро Nox на Node.js, поэтому Python-пакет непосредственно не подключать.
- **LangGraph — новый MIT-кандидат, около 44,6 тыс. звёзд.** [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph) помечен MIT, а пакет langgraph в libs/langgraph имеет собственную MIT-лицензию. Он предназначен для stateful циклических агентов; источник — state/graph оркестрация и human-in-the-loop, сравнить с src/agent/loop.js и src/missions/. Основной репозиторий Python, поэтому это прежде всего архитектурный донор ([страница пакета](https://github.com/langchain-ai/langgraph/blob/main/libs/langgraph/pyproject.toml), [репозиторий](https://github.com/langchain-ai/langgraph)).
- **Pi Mono — новый MIT-кандидат с не подтверждённым актуальным числом звёзд.** Название ведёт к [badlogic/pi-mono](https://github.com/badlogic/pi-mono); README, доступный в копиях проекта, называет его TypeScript-монорепозиторием с пакетами packages/agent-core, packages/coding-agent, pi-ai, pi-tui и pi-web-ui, и заявляет MIT ([README-копия с каталогом пакетов](https://github.com/michalliu/badlogic_pi-mono)). Прямая страница GitHub в этой проверке не открылась; вторичная запись за январь 2026 показывает 2,192 звезды, а другая более поздняя заметка говорит 40k+ без прямого API-среза. Поэтому число звёзд и LICENSE на текущем SHA остаются gaps. При подтверждении это сильный Node/TypeScript источник для цикла агента и LLM/tool API.
- **Supermemory — новый MIT-кандидат, 31,6 тыс. звёзд.** Профиль проекта GitHub показывает supermemoryai/supermemory как TypeScript-репозиторий с MIT меткой; в главном репозитории есть apps/, packages/ и skills/supermemory/ ([профиль организации](https://github.com/supermemoryai), [корневая LICENSE](https://github.com/supermemoryai/supermemory/blob/main/LICENSE)). README проект описывает как memory/context engine, пригодный для self-host; сравнивать стоит с src/memory/store.js, src/memory/learn.js и src/rag/index.js. Подпапка skills/supermemory имеет отдельный Apache-2.0 LICENSE и не должна считаться частью MIT-кода ([LICENSE навыка](https://github.com/supermemoryai/supermemory/blob/main/skills/supermemory/README.md)); для переносимого кода всё равно проверить корневой LICENSE и целевой package на зафиксированном SHA.
- **Chonkie — новый MIT-кандидат, 4,8 тыс. звёзд.** Каноническая страница GitHub сейчас [feyninc/chonkie](https://github.com/feyninc/chonkie); README ссылается на прежнее имя chonkie-inc/chonkie. GitHub показывает MIT, исходники — src/chonkie/, тесты — tests/. Это Python-библиотека chunking/ingestion для RAG, годится для сравнения сегментации документов с src/rag/index.js, но не является прямой Node-зависимостью ([репозиторий](https://github.com/feyninc/chonkie)).
- **Уже учтённый: Microsoft UFO.** [microsoft/UFO](https://github.com/microsoft/UFO) — MIT, около 10,2 тыс. звёзд; важные каталоги включают ufo/, model_worker/, dataflow/, vectordb/ и tests/. В каталоге доноров уже есть полный снимок с подтверждённой MIT-лицензией на SHA eae3c0a8, поэтому это дубль, а не новая находка ([репозиторий и дерево](https://github.com/microsoft/UFO)).
- **Уже учтённые: OpenHands и SDK.** [OpenHands/OpenHands](https://github.com/OpenHands/OpenHands) показывает около 92,7 тыс. звёзд и MIT; он владеет UI/control center, а [OpenHands/software-agent-sdk](https://github.com/OpenHands/software-agent-sdk) — SDK, Agent Server, tools, workspaces, events и REST API; SDK показывает около 1,4 тыс. звёзд. Каталог уже содержит оба адреса, но только MIT API-метки, без скачанных исходников и закреплённой ревизии. SDK поддерживает Python, TypeScript и REST, поэтому он может быть отдельным кандидатом на следующий этап скачивания, но повторно в список новых не добавлять ([OpenHands README/architecture](https://github.com/OpenHands/OpenHands), [SDK README](https://github.com/OpenHands/software-agent-sdk)).
- Для сравнения дублировать не нужно: [OpenInterpreter/open-interpreter](https://github.com/OpenInterpreter/open-interpreter) уже есть в каталоге и Apache-2.0; это не проходит MIT-фильтр.

### Inferences

- Самая высокая польза для Nox: OpenAdapt (проверяемые детерминированные действия), Midscene.js (визуальное взаимодействие и отчёты шага), Agent Zero (структура инструментов и плагинов), Silero VAD (низкоуровневое распознавание речи/тишины).
- Node/TypeScript приоритет: OpenAdapt пакеты монорепозитория, Midscene.js, OpenCode, Pi Mono и Supermemory. Python-фреймворки Pydantic AI, LangGraph и Chonkie лучше изучать как образцы решений, не добавляя runtime на Python без отдельной необходимости.
- Для каждого настоящего заимствования всё ещё нужно закрепить commit SHA, проверить точный файл LICENSE/NOTICE, файл-модель и транзитивные зависимости. Здесь выполнена веб-проверка, а не скачивание снимков и не юридическое заключение.

### Gaps

- Pi Mono: прямая страница GitHub не загрузилась, актуальные звёзды и текущий текст LICENSE не подтверждены. Вторичные звёздные значения расходятся.
- OpenHands SDK и UFO уже в каталоге, однако SDK пока не скачан; UFO имеет подтверждённый снимок на старом SHA и актуальность отдельных модулей нужно оценивать отдельно.
- Для OpenAdapt/Midscene/Supermemory/Pydantic AI/Pi Mono пока не закреплялись ревизии и не проверялись локально все package-level LICENSE и сторонние компоненты.
- У Silero VAD есть противоречие в README badge; LICENSE в корне MIT, но права на каждый готовый вес отдельно не установлены.

## Apache, BSD, AGPL и смешанные лицензии

### Takeaway

Следующие проекты не являются MIT-кандидатами по требованию владельца. Среди них есть технически близкие к Nox источники для MCP, браузерной автоматизации, памяти и голоса; их можно использовать как описание подхода, а не добавлять исходный код в MIT-донорский набор.

### Cited Findings

- **Goose — Apache-2.0, около 54,5 тыс. звёзд.** Актуальный URL — [aaif-goose/goose](https://github.com/aaif-goose/goose); старая ссылка block/goose переехала. Проект работает на desktop Windows/macOS/Linux и подключает расширения через MCP. Это полезно для расширяемости и MCP-потоков, но код Apache-2.0 не проходит MIT-фильтр ([GitHub](https://github.com/aaif-goose/goose)).
- **Open Interpreter — Apache-2.0, около 68,8 тыс. звёзд, уже есть в каталоге.** GitHub показывает [openinterpreter/openinterpreter](https://github.com/openinterpreter/openinterpreter); старая запись OpenInterpreter/open-interpreter тоже в каталоге и обозначает Apache-2.0. Это coding agent, не новый MIT донор ([репозиторий](https://github.com/openinterpreter/openinterpreter)).
- **Agent S — Apache-2.0, 12,9 тыс. звёзд.** [simular-ai/Agent-S](https://github.com/simular-ai/Agent-S) содержит gui_agents/, agent_s4/, evaluation_sets/ и tests/. Он управляет реальным GUI; setup.py включает pyautogui и на Windows pywinauto/pywin32. Полезен для компьютерного зрения и оценки действий, но Python и Apache-2.0, поэтому код не проходит фильтр ([репозиторий](https://github.com/simular-ai/Agent-S), [зависимости](https://github.com/simular-ai/Agent-S/blob/main/setup.py)).
- **UI-TARS и UI-TARS-desktop — Apache-2.0.** Модельно-исследовательский [bytedance/UI-TARS](https://github.com/bytedance/UI-TARS) показывает около 11,5 тыс. звёзд. [bytedance/UI-TARS-desktop](https://github.com/bytedance/UI-TARS-desktop) показывает около 39,6 тыс. звёзд; приложения находятся в apps/ui-tars, SDK — packages/ui-tars/sdk, код конкретного SDK явно имеет SPDX Apache-2.0. Desktop README говорит о локальном/удалённом computer и browser operators. Сильный ориентир по GUI-агенту, но обе репозитории не MIT; лицензии весов модели проверять отдельно ([модель](https://github.com/bytedance/UI-TARS), [desktop](https://github.com/bytedance/UI-TARS-desktop), [файл SDK](https://github.com/bytedance/UI-TARS-desktop/blob/main/packages/ui-tars/sdk/src/Model.ts)).
- **Playwright MCP — Apache-2.0, около 38,1 тыс. звёзд.** Точный проект [microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp), npm-пакет @playwright/mcp, Node >=18 и Apache-2.0 в package.json. Очень близко к Browser Bridge/MCP Nox; сравнить CLI, сервер и браузерные инструменты, но код не заносить в MIT-список ([package.json](https://github.com/microsoft/playwright-mcp/blob/main/package.json), [репозиторий](https://github.com/microsoft/playwright-mcp)).
- **Skyvern — AGPL-3.0, около 23 тыс. звёзд.** [Skyvern-AI/skyvern](https://github.com/Skyvern-AI/skyvern) описывает визуальную браузерную автоматизацию без жёстко заданных XPath; корневой README явно называет AGPL-3.0. Основной Python-код можно изучить как reference, но не переносить как MIT-донор ([README/License](https://github.com/Skyvern-AI/skyvern)).
- **Graphiti — Apache-2.0, около 31 тыс. звёзд.** [getzep/graphiti](https://github.com/getzep/graphiti) — библиотека temporal knowledge graph; исходный Python пакет graphiti_core и примеры. В репозитории есть mcp_server/ и server/, но документация предупреждает, что reference-серверы не имеют аутентификации, авторизации и защиты от prompt injection и не предназначены для production. Это хорошее сравнение для памяти и поиска, не MIT-код ([README](https://github.com/getzep/graphiti), [package license](https://github.com/getzep/graphiti/blob/main/pyproject.toml)).
- **Letta Code — Apache-2.0, 3,8 тыс. звёзд.** [letta-ai/letta-code](https://github.com/letta-ai/letta-code) — актуальный TypeScript agent harness, terminal UI и App Server; корневая LICENSE также исключает название Letta/Letta Code, логотип, изображения и ASCII art. Для Nox релевантны память и опыт агента, но ни код, ни бренд не MIT ([README](https://github.com/letta-ai/letta-code), [LICENSE](https://github.com/letta-ai/letta-code/blob/main/LICENSE)).
- **Mem0 — Apache-2.0, 68,6 тыс. звёзд; уже разобран в предыдущей заметке, но отсутствует в каталоге.** Прямая текущая [mem0ai/mem0](https://github.com/mem0ai/mem0) имеет Apache-2.0 в корневом LICENSE, папки mem0/, mem0-ts/, server/ и интеграции. Сторонние каталоги с более старой датой показывали MIT, но текущий официальный GitHub page и текущий LICENSE показывают Apache-2.0 — этот первичный источник имеет приоритет. Код полезен как memory layer, однако не проходит MIT-фильтр ([текущая LICENSE](https://github.com/mem0ai/mem0/blob/main/LICENSE), [репозиторий и дерево](https://github.com/mem0ai/mem0)).
- **LiveKit Agents — Apache-2.0, 14,9 тыс. звёзд.** [livekit/agents](https://github.com/livekit/agents) — Python framework для realtime voice/video; отдельный [agents-js](https://github.com/livekit/agents-js) тоже TypeScript, но Apache-2.0. Turn detection models идут по отдельной LiveKit Model License. Для Nox можно сравнить поток, перебивание и realtime events, но framework не MIT и модельные лицензии отдельны ([Python repo](https://github.com/livekit/agents), [организация и JS sibling](https://github.com/orgs/livekit/repositories), [model license](https://github.com/livekit/agents/blob/main/MODEL_LICENSE)).
- **Pipecat — BSD-2-Clause; в предыдущей заметке уже отмечен как non-MIT.** [pipecat-ai/pipecat](https://github.com/pipecat-ai/pipecat) — Python realtime voice/multimodal agent framework. LICENSE и pyproject.toml прямо указывают BSD-2-Clause. Сравнить аудио-conveyor, не копировать как MIT ([LICENSE](https://github.com/pipecat-ai/pipecat/blob/main/LICENSE), [pyproject](https://github.com/pipecat-ai/pipecat/blob/main/pyproject.toml)).
- **Speech-to-Speech — Apache-2.0, 13,6 тыс. звёзд.** Точное совпадение названия — [huggingface/speech-to-speech](https://github.com/huggingface/speech-to-speech), исходник src/speech_to_speech/, с модульной локальной цепочкой VAD → STT → LLM → TTS и WebSocket/WebRTC OpenAI Realtime protocol. Некоторые включаемые pretrained weights, например OmniVoice и Phonon 40M, имеют CC-BY-NC-4.0; значит root Apache не распространяется на эти веса ([README и LICENSE](https://github.com/huggingface/speech-to-speech)).
- **Mastra — Apache-2.0 для основной части, около 29,1 тыс. звёзд.** [mastra-ai/mastra](https://github.com/mastra-ai/mastra) — TypeScript/Node агентный framework. Корневой LICENSE.md говорит: всё вне директорий с именем ee/ — Apache-2.0; содержимое ee/ распространяется по отдельной Mastra Enterprise License, требующей соглашения для production. Хороший Node ориентир для tools/workflows, но не MIT-кандидат ([LICENSE mapping](https://github.com/mastra-ai/mastra/blob/main/LICENSE.md), [EE License](https://github.com/mastra-ai/mastra/blob/main/ee/LICENSE)).
- **Официальные MCP Servers — лицензия смешана по вкладам.** [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers) показывает около 91,9 тыс. звёзд. Текущая LICENSE указывает Apache-2.0 для новых вкладов/разрешённых к перелицензированию, MIT для старых вкладов без согласия на перелицензирование, CC-BY-4.0 для документации, кроме спецификаций. Это не однозначный MIT snapshot. README ограничивает репозиторий обучающими reference servers; production готовность и безопасность отдельно не гарантируются. Считать отдельный код MIT можно только после file-level подтверждения происхождения/лицензии ([LICENSE](https://github.com/modelcontextprotocol/servers/blob/main/LICENSE), [README](https://github.com/modelcontextprotocol/servers)).
- **MCP TypeScript SDK не перечислен отдельно на скриншотах, но влияет на оценку MCP Servers:** у SDK тот же переход MIT → Apache для новых вкладов и CC-BY для docs; не копировать репозиторий целиком ([SDK LICENSE](https://github.com/modelcontextprotocol/typescript-sdk/blob/main/LICENSE)).

### Inferences

- Из не-MIT проектов наиболее полезны для архитектурного сравнения Playwright MCP (браузер), Agent S/UI-TARS (GUI действия), Graphiti/Mem0/Letta (память), LiveKit/Pipecat/Speech-to-Speech (голос), Goose/Mastra (MCP и tool runtime).
- Лицензия framework не лицензирует автоматически модели, веса, изображения, брендинг и внешние сервисы. Для Nox нужны отдельные проверки моделей и ресурсов.
- В открытом списке кандидатов надо разделять «прочитать как референс» и «можно копировать код». Пользовательский MIT-фильтр включает только подтверждённые MIT-компоненты, а Apache/BSD/AGPL остаются отдельно.

### Gaps

- Точный путь отдельных source modules не зафиксирован для Goose, Letta Code, Playwright MCP, Skyvern, LiveKit Agents, Pipecat, Pydantic AI и LangGraph; в карточках выше даны только проверенные корневые/пакетные точки входа.
- Число звёзд Pipecat не было заново подтверждено официальной страницей в этом проходе; оно не нужно для решения по лицензии.
- Для MCP Servers и MCP TypeScript SDK невозможно безопасно выбрать MIT-фрагменты только по сегодняшнему LICENSE без проверки авторства и согласия автора в конкретной ревизии.
- UI-TARS model weight license, реальные лицензии отдельных checkpoint-ов LiveKit, Silero и Speech-to-Speech требуют проверки по самим model cards/release artifacts.

## Списки проектов и итоговый порядок

### Takeaway

Списки пригодны как каталоги для продолжения поиска; ни один список сам по себе не является кодовым донором Nox. Наиболее полезен Awesome-CUA от reacher-z: он имеет источники для записей, пути к данным и явные поля лицензии; конкурирующие списки с названием Awesome Computer Use / Awesome Personal Agents не имеют однозначной ссылки без изображения с URL.

### Cited Findings

- **Awesome CUA — точный найденный GitHub: [reacher-z/Awesome-CUA](https://github.com/reacher-z/Awesome-CUA), 554 звезды.** Репозиторий публикует source-backed catalog, хранит JSONL/SQLite и scripts/catalog.py; сам код и аннотации MIT, а связанные upstream проекты сохраняют собственные лицензии. Данные содержат поля kind/status/source/license, поэтому список хорошо подходит для дальнейшего поиска и перепроверки по источникам ([README](https://github.com/reacher-z/Awesome-CUA), [LICENSE](https://github.com/reacher-z/Awesome-CUA/blob/main/LICENSE)).
- **Awesome AI Agents: [e2b-dev/awesome-ai-agents](https://github.com/e2b-dev/awesome-ai-agents), 30,8 тыс. звёзд.** Это список автономных AI agents; LICENSE.md — CC BY-NC-SA 4.0, поэтому сам список/текст не включать в коммерческую поставку как MIT код ([README](https://github.com/e2b-dev/awesome-ai-agents), [LICENSE.md](https://github.com/e2b-dev/awesome-ai-agents/blob/main/LICENSE.md)).
- **Awesome AI Agents альтернативы — названия не уникальны.** Также найдены [aloth/awesome-ai-agents](https://github.com/aloth/awesome-ai-agents), 85 звёзд и CC0-1.0, и [tioraicom/awesome-ai-agents](https://github.com/tioraicom/awesome-ai-agents), чья лицензия по README — CC BY 4.0. Точный проект со скриншота определить нельзя без URL.
- **Awesome Computer Use тоже неоднозначен.** [12britz/awesome-computer-use](https://github.com/12britz/awesome-computer-use) показывает 18 звёзд и обещает каталог из 139 проектов; на странице есть License, но текст лицензии в этой проверке не подтверждён. README ссылается на [ranpox/awesome-computer-use](https://github.com/ranpox/awesome-computer-use) как старый список и на другие GUI-agent каталоги. Ни одну из этих ссылок не считать кодовым донором до чтения LICENSE.
- **Awesome Personal Agents — найдены два разных точных названия.** [upgundecha/awesome-personal-agents](https://github.com/upgundecha/awesome-personal-agents) показывает 2 звезды и содержит фильтр по открытой лицензии/звёздам проектов; LICENSE-файл на корне не был найден в представленных материалах. [ahmadyan/awesome-personal-agents](https://github.com/ahmadyan/awesome-personal-agents) — активно структурированный список личных агентов, памяти, сред выполнения и мостов; точное число звёзд и LICENSE страницы в этой проверке не установлено из-за timeout. Название со скриншота без URL не даёт выбрать одно из них.
- Числа звёзд для строк выше — значения страниц GitHub во время проверки, не критерии надёжности. Каталоги перечисляют upstream-проекты, и для каждого кода лицензия должна проверяться отдельно.

### Inferences

- Рекомендованный порядок доноров на следующем этапе: (1) OpenAdapt packages/flow и packages/agent, (2) Midscene.js браузер/desktop SDK и проверка ожидаемого результата, (3) Agent Zero tools/plugins, (4) Silero VAD только после проверки модели, (5) OpenHands SDK как уже заведённая, но не скачанная карточка.
- Отдельно использовать reacher-z/Awesome-CUA как постоянный индекс новых CUA-кандидатов; сначала фильтровать записи по MIT и Windows/web fit, затем брать только первичные ссылки. У списка свои MIT-условия, у каждого upstream кода — свои.
- Не следует смешивать директории под общим именем проекта: для Cua, Activepieces-подобных монорепозиториев, Mastra, MCP и Supermemory проверять лицензии целевого подпроекта и ассетов отдельно.

### Gaps

- Не известно, какой именно URL стоял за тремя ярлыками «Awesome Computer Use», «Awesome Personal Agents» и «Awesome AI Agents» на присланных скриншотах; найденные источники — кандидаты по названию, не подтверждённое совпадение ссылок.
- Для 12britz/awesome-computer-use не прочитан полный текст LICENSE; для ahmadyan/awesome-personal-agents не подтверждены stars/license. Их нельзя описывать как MIT-списки.
- Снимки репозиториев не скачивались. Следующий точный шаг — закрепить SHA и проверить LICENSE/NOTICE и файлы-кандидаты для новых MIT-проектов.
