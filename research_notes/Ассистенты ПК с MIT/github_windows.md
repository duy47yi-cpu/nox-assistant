# GitHub desktop assistant candidates

## Which low-profile GitHub projects meet the MIT and PC-assistant criteria?

### Takeaway

The closest directly reusable Electron references are Aura and Adamdesgns/jarvis-local-assistant; JARVIS-OS and ndunl075/Jarvis are unusually useful for permission-gated Windows actions, voice loops, and tests. All confirmed counts below were checked on 2026-11-08 and are 0–24 stars. Treat stars as a snapshot, not a quality score.

### Cited Findings

- **Aura — 0 stars; MIT; Electron/TypeScript/Node.** Desktop assistant for Windows/Linux with hotkey corner window, chat/voice, screen help, dictation, agent actions, local Ollama or Gemini. The root has `agent/`, `protocol/`, `src/`, `test/`, `LICENSE`, and `THIRD_PARTY_NOTICES.md`; GitHub labels the repo MIT. Best first inspection: how the agent plans, checks results, and asks before consequential actions, plus the agent/protocol split. UI is German, which limits direct reuse of copy. [Repository and star count](https://github.com/fischersase/aura); [README architecture, behavior and license](https://github.com/fischersase/aura#readme)
- **Adamdesgns/jarvis-local-assistant — 4 stars; MIT; Electron/JavaScript.** Strong Nox overlap: local wake word and speech, Ollama with optional Claude/OpenAI, reminders, memory, routines, document Q&A, watched folders, and confirmation-gated file operations. Root exposes `main.js`, `preload.js`, split voice/stop preloads, `core/`, `src/`, and `test/`; README says 32 tests and Electron packaging. Inspect the main/preload boundary, local data handling, safety checks, and voice diagnostics. [Repository, tree, stars, and license](https://github.com/Adamdesgns/jarvis-local-assistant); [README feature and build details](https://github.com/Adamdesgns/jarvis-local-assistant#readme)
- **ndunl075/Jarvis — 16 stars; MIT; Python/Windows.** Local voice assistant with wake word, Whisper, Piper, Ollama, command palette, system tray, MCP tool registry, configurable hotkeys and app list, and a clipboard-history feature. Root includes `jarvis/`, `tests/`, `SPEC.md`, and `BUILD.md`. Useful for studying a small Windows assistant's command routing, local voice loop, tool extension points, and tests; it is not an Electron donor. [Repository, stars, files and license](https://github.com/ndunl075/Jarvis); [README](https://github.com/ndunl075/Jarvis#readme)
- **PHENOMVALENCE/JARVIS-OS — 2 stars; MIT; Python/Windows.** Local-first voice assistant with screen reading, file search, window control and reminders. The README describes typed actions with declared permissions/risk, confirmation for typing/closing/deleting, a hash-chained action log, privacy mode, and effect verification. Root includes `jarvis_os/`, `plugins/`, `tests/`, `ARCHITECTURE.md`, `COMMANDS.md`, and `SECURITY.md`. One of the best low-profile references for Nox's tool policy and verification design. [Repository, stars, files and license](https://github.com/PHENOMVALENCE/JARVIS-OS); [README safety and behavior](https://github.com/PHENOMVALENCE/JARVIS-OS#readme)
- **jrubiosainz/desktop-assistant — 24 stars; MIT; Electron/JavaScript.** Electron chat client with GitHub Copilot SDK, Windows control tools, Microsoft 365 integrations, screenshots, global shortcuts, tray, streaming, and dangerous-operation confirmation dialogs. Root has `src/`, `renderer/`, and `test-sdk.mjs`. Useful for tool catalog/UI patterns and confirmations, but its brain is Copilot SDK/cloud centric, so it is less aligned with Nox's provider-neutral/local architecture. README says 60+ tools while the repo's About blurb says 44, so don't treat the tool count as stable. [Repository, tree, stars and license](https://github.com/jrubiosainz/desktop-assistant); [README](https://github.com/jrubiosainz/desktop-assistant#readme)
- **xarmaq/Jarvis — 0 stars; MIT; Python + React/Tauri.** Especially relevant language/platform concepts: Russian/English wake words, local voice, UI Automation, OCR and visual grounding, app/window/media controls, Chromium DevTools, and a dynamic island. README points to `core/ears.py`, `turn.py`, `stt.py`, `resolve.py`, `brain.py`, `reflexes.py`, `hands.py`, `browser.py`, `eyes.py`, `grounding.py`, and `island/src/`. It calls itself experimental; README also states dangerous-action confirmation defaults off and audio/transcripts are recorded. Study as a feature reference only; review its safety and data handling before borrowing patterns. [Repository, stars and license](https://github.com/xarmaq/Jarvis); [README component map and caveats](https://github.com/xarmaq/Jarvis#readme)
- **Ashutosh0x/jarvis — 4 stars; MIT; Electron/Node, local inference.** Large local-first desktop assistant project with Electron service supervision and local Whisper/Ollama/embeddings/vision. The root includes `electron.js`, `computerUse.js`, `eventBus.js`, `server/`, `src/`, and `tests/`; `computerUse.js` is a compact, targeted starting point for desktop-control ideas, while `electron.js` is a very large (about 7,700-line) supervisor file and probably not a model for Nox modularity. [Repository, files, stars and license](https://github.com/Ashutosh0x/jarvis); [README architecture and voice pipeline](https://github.com/Ashutosh0x/jarvis#readme); [computerUse.js](https://github.com/Ashutosh0x/jarvis/blob/master/computerUse.js)
- **MoHan-PC-Desktop-Assistant — 3 stars; MIT applies to source code, not every repository asset; Python/PySide6.** Interesting for permission-gated tools, editable long-term memory, tasks, work timers, and a 2.5D character UI. Root includes `application/`, `domain/`, `docs/` and a 250-commit history. Critical license split: characters, voices, built-in appearances, character icons and promotional media are CC BY-NC-ND 4.0 and expressly outside MIT. Only consider code with its MIT notice; do not copy/bundle the character assets under an assumption of MIT. [Repository, stars and overview](https://github.com/flameblade-studio/MoHan-PC-Desktop-Assistant); [README license boundary](https://github.com/flameblade-studio/MoHan-PC-Desktop-Assistant#readme)

### Inferences

- For fast Nox-specific study, start with Aura's `agent/` + `protocol/`, Adam's Electron `main.js`/preloads, and JARVIS-OS's typed action and verification design; those match Nox's Electron bridge, policy decisions, and `verify` contract most closely. This ranking is an inference from the documented stack and features above.
- Low star counts plus mature-looking docs/tests can make these repositories good donor *references*, but neither stars nor README claims establish runtime quality. Review source, dependency licenses, and tests before porting any implementation.
- Code being under MIT does not automatically make bundled models, voices, icons, fonts, screenshots, or npm/Python dependencies MIT. Check each repository's license and third-party notices at the file level before copying or bundling.

### Gaps

- GitHub's tree pages for nested directories were intermittently inaccessible through the web fetcher; for several projects the verified detail is at folder level, and filenames are drawn from their own README component maps.
- This pass verifies repository-level license signaling and cited license boundaries, but is not a full provenance audit of each source file or dependency.
- Commit histories and star counts were observed from GitHub pages on 2026-11-08 and may change.
