# Nox Assistant — релизная папка (первый релиз)

Это чистая копия только нужного: приложение `apps/jarvis-desktop`, сервер `apps/nox-server`, документы продукта. Здесь нет старых папок разработки, мусорных сборок и видео. Всё уже проверено: тесты приложения 1505 из 1505, сервера 16 из 16.

## Что здесь лежит

| Папка/файл | Зачем |
|---|---|
| `apps/jarvis-desktop` | Само приложение (окно, ядро, тесты, сборка установщика) |
| `apps/nox-server` | Сервер аккаунтов (пока нужен только для своего варианта с аккаунтами) |
| `docs/` | Краткая документация: план бизнеса, журнал проверок, бриф интерфейса |
| `workspace/` | Рабочая папка Джарвиса (входящие, отчёты) — создана пустой |
| `AGENTS.md` | Карта проекта: где что лежит, правила |
| `PRODUCT.md`, `DESIGN.md` | Что за продукт и как устроен дизайн окна |
| `.env` | Ключи (скопированы из рабочего репозитория как есть, я их не читал) |
| `package.json` | Команды запуска из корня |

## Как запустить

Нужен Node.js 20+ (стоит). Из папки релиза:

```powershell
npm start                 # запуск приложения (из корня D:\nox-release)
```

Сервер нужен, только если включаешь аккаунты:

```powershell
cd apps\nox-server
node index.js             # адрес и настройки в apps/nox-server/README.md
```

## Как проверить перед сборкой

```powershell
npm test                  # тесты приложения из корня (все должны быть зелёные)
cd apps\nox-server; npm test   # тесты сервера
```

## Ключи в .env

- `NOX_GMAIL_CLIENT_ID`, `NOX_GMAIL_CLIENT_SECRET` — почта Google (ты уже сделал проект в Google Cloud).
- `NOX_BRAIN_KEY`, `NOX_SMART_KEY` — ключи модели, если приложение работает без сервера.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_CHAT` — если нужен Telegram-мост.
- `FISH_API_KEY` — голос Fish Audio (не обязательно).

Первое подключение Gmail живьём сделает один вход в браузер — скажешь, когда готов.

## Сборка установщика (когда дизайн готов)

```powershell
cd apps\jarvis-desktop
npm run dist              # соберёт установщик в apps\jarvis-desktop\dist\
```

Первая сборка скачает инструменты electron-builder (это бесплатно, нужен интернет). Имя и иконки уже настроены в `package.json` приложения.

## Что важно

- Настоящая папка данных создаётся при первом запуске здесь же: `data\`. В неё попадут настройки и переписка — она локальная.
- Папки `data\` и `.env` в установщик не попадают.
- Папка разработки `D:\nox-assistant` остаётся рабочей: там идут исправления, отсюда позже переносим обновления.
